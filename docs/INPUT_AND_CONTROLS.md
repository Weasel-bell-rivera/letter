# 输入设备与控制

## 首批目标设备（已确定）

- 首批版本仅支持键盘和鼠标。
- 首批验收不要求手柄操作、手柄按键提示或手柄导航。
- 手柄属于后续候选范围，不能阻塞首批纵向切片开发。

## Unity实现约束

- 输入应通过 Unity Input System 的 Input Action 表达，玩法逻辑不得直接依赖具体按键。
- 移动、跳跃、放置镜子、收回镜子、手动重置和交互应使用独立Action。
- 镜子放置不依赖鼠标指针或自由瞄准：玩家面向并紧邻特殊墙壁时优先放到墙壁，否则尝试放在玩家脚下。
- 首批仍必须使用 Input Action，不能因为仅支持键鼠而在玩法代码中直接读取具体按键。
- 后续增加手柄时，只需要提供等价动作绑定，不需要增加指针选点机制。
- 首批UI只显示键盘和鼠标提示；后续设备提示切换不在首批范围。

## 当前已知绑定

- 向左：`A` 或左方向键。
- 向右：`D` 或右方向键。
- 跳跃：`Space`。
- 鼠标左键：尝试放置镜子。
- 鼠标右键：收回镜子。
- 手动重置房间：`R`。
- 主动交互：`E`。
- 暂停：`Esc`。
- 普通道具通过接触自动拾取，不需要按 `E`。
- `E` 保留给对话或明确要求主动操作的特殊机关。

## Input Actions

首批至少定义以下Action：

- `Move`
- `Jump`
- `PlaceMirror`
- `RecallMirror`
- `ResetRoom`
- `Interact`
- `Pause`

方向键和 `A`/`D` 必须映射到同一个 `Move` Action，玩法代码不得分别处理。

具体放置目标与合法性规则见 `docs/MIRROR_MECHANIC.md`。
