# 玩家移动规则

## 基础参数

- 水平移动速度：6 Unity units/s
- 地面加速度：40 units/s²
- 地面减速度：50 units/s²
- 空中控制系数：0.7
- 标准跳跃高度：3 Unity units
- 到达跳跃最高点的时间：0.35秒
- 土狼时间：0.1秒
- 跳跃输入缓冲：0.12秒
- 最大下落速度：15 units/s
- 跳跃支持可变高度：提前松开 `Space` 会截短上升速度；持续按住可达到标准跳跃高度。
- 不支持二段跳。
- 不支持墙跳。

## 设计要求

- 所有普通房间使用同一套基础移动参数。
- 不允许在单个关卡中私自修改玩家速度或跳跃高度。
- 特殊元素影响移动时，必须通过明确的状态或区域效果实现。
- 玩家、镜像以及关卡尺寸必须基于同一套移动尺度设计。
- MirrorClone复用Player的Collider尺寸、移动速度、加速度、减速度、跳跃高度、土狼时间、输入缓冲和最大下落速度。
- MirrorClone复用Player的视觉尺寸、Pivot、Sprite轮廓和动画基础配置，不得通过额外Transform缩放改变角色大小。
- Jump的按下、持续和松开同时传给Player与MirrorClone；双方分别使用自身的落地状态、土狼时间和输入缓冲决定是否起跳。
- Player未成功起跳不阻止MirrorClone起跳，MirrorClone未成功起跳也不影响Player。
- MirrorClone生成时与Player水平镜像，之后根据自身映射后的实际移动方向更新视觉朝向。
- 特殊墙壁模式只旋转MirrorClone的输入与局部物理方向，不改变运动参数数值。
- 玩家当前朝向由最后一次非零水平输入决定；松开输入后保留该朝向，用于镜子放置检测。

## 雪区寒冰地面效果

- `FrozenGround`是明确的区域表面状态，不通过Tile、Sprite或GameObject名称判断。
- Player和MirrorClone接触同类寒冰地面时使用完全一致的运动规则。
- 寒冰地面只改变沿接触表面切线方向的加速与减速。
- 最高移动速度、跳跃高度、土狼时间、跳跃缓冲、空中控制和最大下落速度沿用默认移动参数。
- 离开寒冰地面后恢复默认地面加速度和减速度。
- 同类寒冰地面参数由雪区统一配置，具体房间不得覆盖。

| 参数 | 当前状态 |
|---|---|
| 寒冰地面加速度 | 0 units/s² |
| 寒冰地面减速度 | 0 units/s² |

Player或MirrorClone稳定接触寒冰地面时，当前切向速度保持不变：输入不会使其加速、反向或主动刹车，松开输入也不会减速。跳离寒冰后立即恢复默认空中控制；接触普通地面后立即恢复默认地面加速度和减速度。敌人踩冰冻结属于敌人状态规则，不依赖这两个数值；完整区域规则见`docs/regions/SNOW_REGION.md`。

## 地面传送带表面速度

- 地面传送带是全局通用表面机制，完整规则见`docs/systems/CONVEYOR_SYSTEM.md`。
- Player和MirrorClone通过相同的`ISurfaceMotionProvider2D`读取当前实际支撑面的世界空间速度。
- 角色主动移动继续使用`DefaultPlayerMovement.asset`；传送带速度作为环境表面速度与主动速度相加，不修改基础移动资产。
- 默认传送带速度为`2.5 units/s`，实例允许范围为`0.5～4.5 units/s`，始终低于基础最大移动速度`6 units/s`。
- 角色留在同一传送带上时，已经施加的表面速度必须在下一固定步计算前扣除再重新加入，不能逐帧累加。
- 进入新传送带、走到静态地面、跳起或离开边缘时保留当前世界速度，再由对应的地面或空中加减速规则处理。
- 传送带只在其上表面是角色当前局部重力方向上的实际支撑面时生效；侧面、底面和空中重叠不生效。
- 落地查询命中多个合法支撑Collider时，Player与MirrorClone使用同一套确定性支撑选择规则：优先保持仍然有效的上一支撑，再选择脚底下最近的合法表面。
- 查询结果顺序不得影响支撑选择；接缝处每个固定物理步只能选择一个Collider和一份表面速度。
- 传送带启停不得改变角色面向、输入序列、跳跃序列、寒冰状态或局部重力。

## 移动平台表面速度

- 通用移动平台规则以`docs/systems/MOVING_OBJECTS.md`为权威来源，并与传送带共用`ISurfaceMotionProvider2D`支撑面速度接口。
- 平台先在固定物理步中发布当步世界速度；Player和MirrorClone随后分别读取自身实际支撑Collider，在各自控制器中只合成一次。
- 角色输入、重力和跳跃按照相对平台的速度计算，基础参数仍来自`DefaultPlayerMovement.asset`；平台速度不得写入或覆盖该资产。
- 留在同一平台时，下一固定步必须先扣除上一物理步已经合成的平台速度，再加入当前平台速度，避免速度逐帧累加或在端点反向时残留。
- 平台不得直接改写角色的`Transform.position`或`Rigidbody2D.position`。平台和角色均启用插值时，必须保持各自Rigidbody插值历史连续。
- 角色离开平台边缘或起跳后不再接收平台后续速度，但保留离开瞬间的世界速度，随后由现有空中控制、重力和最大下落速度处理。
