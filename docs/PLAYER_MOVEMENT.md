# 玩家移动规则

## 基础参数

- 水平移动速度：6 Unity units/s
- 地面加速度：40 units/s²
- 地面减速度：50 units/s²
- 空中控制系数：0.7
- 标准跳跃高度：3 Unity units
- 到达跳跃最高点的时间：0.35秒
- 土狼时间：0.1秒
- 跳跃输入缓冲：0.12秒
- 最大下落速度：15 units/s
- 跳跃支持可变高度：提前松开 `Space` 会截短上升速度；持续按住可达到标准跳跃高度。
- 不支持二段跳。
- 不支持墙跳。

## 设计要求

- 所有普通房间使用同一套基础移动参数。
- 不允许在单个关卡中私自修改玩家速度或跳跃高度。
- 特殊元素影响移动时，必须通过明确的状态或区域效果实现。
- 玩家、镜像以及关卡尺寸必须基于同一套移动尺度设计。
- MirrorClone复用Player的Collider尺寸、移动速度、加速度、减速度、跳跃高度、土狼时间、输入缓冲和最大下落速度。
- MirrorClone复用Player的视觉尺寸、Pivot、Sprite轮廓和动画基础配置，不得通过额外Transform缩放改变角色大小。
- Jump的按下、持续和松开同时传给Player与MirrorClone；双方分别使用自身的落地状态、土狼时间和输入缓冲决定是否起跳。
- Player未成功起跳不阻止MirrorClone起跳，MirrorClone未成功起跳也不影响Player。
- MirrorClone生成时与Player水平镜像，之后根据自身映射后的实际移动方向更新视觉朝向。
- 特殊墙壁模式只旋转MirrorClone的输入与局部物理方向，不改变运动参数数值。
- 玩家当前朝向由最后一次非零水平输入决定；松开输入后保留该朝向，用于镜子放置检测。
