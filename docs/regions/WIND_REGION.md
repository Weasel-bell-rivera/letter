# 风之区域

## 区域定位

风之区域围绕气流、方向变化、升降、漂浮和重力变化构建视觉与谜题语言。完整区域结构、房间数量和机制教学顺序仍待设计。

## 已批准机制

### 逐风鳐

- 正式玩法名称：逐风鳐。
- 当前实现名称：`WindRayEnemy2D`。
- 状态：核心行为、首版统一数值、通用Prefab和首个灰盒教学房`WIND_001`已实现；正式美术待后续制作。
- 定位：悬浮在固定守卫点附近、以镜像诱敌为核心解法的风区敌人。
- 感知方式：检测一定世界距离内且无遮挡的Player和MirrorClone，不使用固定风道。
- 目标规则：进入攻击预警时选择距离最近的合格角色并记录其位置；锁定后不切换目标。
- 攻击方式：沿锁定点直线冲刺，不自由追踪、不随机转向。
- 谜题作用：玩家让MirrorClone成为更近的目标，把逐风鳐引离Player的必经路线，再利用喘息与返回窗口通过。
- 命中Player触发完整房间重置；命中MirrorClone只执行镜像死亡与镜子回收，逐风鳐继续完成当前攻击。
- 本机制不产生风力、不改变Player或MirrorClone重力，也不依赖任何风区道具。
- 完整规则见`docs/systems/WIND_RAY_ENEMY.md`。

### 失重之羽

- 当前实现名称：`GravityDisablePickup2D`
- 正式玩法名称：失重之羽
- 区域归属：风之区域
- 状态：已批准为风区机制
- 拾取者：仅 Player 可以完成拾取
- 效果对象：仅 MirrorClone，不影响 Player
- 具体效果：关闭当前镜像及本次房间尝试中后续生成镜像的重力
- 失重只移除MirrorClone的局部重力，不改变镜子的放置方向、镜像生成方向或输入镜射规则。
- 地面镜与特殊墙壁镜在失重状态下都可以生成镜像；特殊墙壁镜仍按核心规则形成上下空间关系，允许镜像垂直生成并与Player重叠。
- 移动和跳跃仍是Player原始输入经过镜面变换后的反向/旋转结果。特殊墙壁模式下，水平移动输入继续映射为镜像垂直移动，跳跃输入继续按镜面方向映射；失重之羽不提供一套独立控制方式。
- 持续时间：持续到本次房间尝试结束，不使用倒计时
- 镜像单独死亡：效果保留
- 玩家死亡或手动重置：效果清除，道具重新出现
- 场景切换：效果清除，不跨房间保留
- 是否允许重复获得：重置后可以再次获得，同一次尝试中不能重复拾取

上述规则为已批准的正式玩法。具体数值、表现和首个教学房仍需通过风区原型确定。

## 实现约束

- 失重之羽不得出现在火区或作为无区域限制的全局道具。
- 风区房间使用该机制前，必须遵守本文已经确认的效果、持续时间和重置规则。
- 逐风鳐使用`docs/systems/WIND_RAY_ENEMY.md`确认的统一数值，具体房间不得逐实例覆盖。
- 逐风鳐必须使用通用敌人Prefab和组件实现，不得在具体风区房间脚本中复制感知、目标选择、攻击或重置规则。
- 区域规则与通用拾取规则发生冲突时，应停止实现并请求确认。
- 通用拾取规则见 `docs/systems/COLLECTIBLE_SYSTEM.md`。
