# 火之区域

## 区域定位

火之区域是一个以高温、燃烧、能量传递和周期性危险为主题的关卡区域。

区域预计包含约50个房间。房间应围绕火元素建立统一的视觉和玩法语言，同时避免重复使用相同的“躲避岩浆”结构。

## 氛围

关键词：

- 炽热
- 压迫
- 活跃
- 不稳定
- 能量积聚
- 短暂爆发

视觉元素可以包括：

- 岩浆
- 火焰
- 火山岩
- 熔化金属
- 灰烬
- 火星
- 热浪
- 锻造设施
- 高温管道
- 被烧焦的遗迹

颜色以暗色岩石、红色、橙色和高亮黄色为主。可交互元素必须与纯装饰性火焰明显区分。

## 核心玩法语言

下列内容是火区玩法语言总览；具体批准状态以紧随其后的“机制批准状态”表为准：

- 持续燃烧：稳定存在的危险区域
- 周期喷发：按照可观察节奏出现和消失
- 热量传递：火焰可以沿指定材料或路径传播
- 点燃：激活火炬、机关或可燃物
- 熔化：改变冰、金属、封锁物或地形状态
- 上升热流：推动玩家、镜子或其他物体
- 冷却凝固：岩浆暂时变成可站立的平台
- 过热：物体在一定时间后进入危险状态

每种行为必须具有稳定、可预测的视觉和声音反馈。

## 首批纵向切片范围

首批火区正式内容只允许使用以下火元素机制：

- 岩浆伤害
- 周期喷发

可以与以下已确认的全局机制组合：

- 镜子与镜像
- 门
- 压力板和Trigger
- 复活与房间重置
- 普通地面、墙壁和移动对象

首批不得提前加入仍为“候选”的火元素机制。候选机制必须经过独立原型和用户批准后才能进入正式房间。

### 岩浆伤害

- Player接触岩浆后死亡，并执行玩家死亡重置。
- MirrorClone接触岩浆后死亡，并执行镜像死亡联动；Player不随之死亡。
- 岩浆危险边界必须与Collider一致且清晰可见。
- 岩浆使用Trigger，不提供实体支撑；角色进入危险区域时立即触发一次死亡事件。
- 镜子不能放置在岩浆表面。
- 岩浆不会破坏已经放置的镜子；镜子进入或接触岩浆Trigger不触发镜子破坏流程。

### 周期喷发

- 喷发采用固定且可预测的循环，不得使用玩家无法判断的随机时序。
- 激活前必须提供清晰预警。
- `Warning`计时阶段继续完整存在，但不显示旧版黄色竖直占位柱；正式预警反馈改由后续地面裂纹、火星或声音表现承担。当前灰盒在正式预警美术接入前只验证阶段与时序。
- Player或MirrorClone在危险阶段接触喷发区域时死亡。
- 周期喷发不会破坏已经放置的镜子。
- 房间重置后，喷发状态和计时恢复到房间定义的初始状态。
- 每个喷发器可以配置预警时长、危险时长、冷却时长和初始相位。
- 喷发只存在`预警 → 危险 → 冷却 → 预警`三个循环状态，不设置独立的“安全状态”；冷却阶段是不造成伤害的通过窗口。
- 默认从预警阶段开始；房间若配置其他初始相位，也不得让玩家在无法观察的情况下立即遭遇危险。
- 多个喷发器可以配置固定相位差，但不得根据玩家位置临时改变周期。

### 周期升降岩浆

- 使用`预警 → 上升 → 顶部停留 → 下降 → 底部停留 → 预警`的确定性循环；不得随机或根据Player位置改变周期。
- 默认参数：预警`1s`、上升`2s`、顶部停留`1.5s`、下降`2s`、底部停留`2.5s`。运动阶段连续匀速。
- 默认从最低位置的预警阶段开始；实例可配置固定初始相位与多个池之间的固定相位差，但出生时不得立即伤害Player。
- 上升前必须通过明显冒泡、变亮和声音提示；下降不追加危险预警。视觉表面与实际Trigger边界始终一致。
- Player进入实际岩浆Trigger立即死亡并执行完整房间重置；MirrorClone进入后只死亡并自动回收镜子。
- 岩浆始终为Trigger，不提供实体支撑，不能放置镜子。上升接触已放置镜子不破坏镜子，下降后镜子仍保持原位。
- 升降岩浆不影响门、压力板、敌人或火球，不触发机关、不阻挡火球、不修改Tilemap。
- 手动重置、Player死亡重置和重新进入房间时恢复实例配置的初始高度、阶段与计时，并清除旧伤害占用。
- 使用通用`RisingLava2D` Prefab；房间只配置最低位置、升高距离、周期和初始相位，视觉与Trigger作为同一移动根一起运动。

### 水平火球投掷敌人

- 正式玩法名称：投火者；实现名称：`HorizontalFireballEnemy2D`。
- 敌人固定在显式配置的守卫位置，只向世界左或右发射独立火球，不巡逻、不追踪。
- 只有位于敌人水平攻击带内且无遮挡的Player或MirrorClone可以触发攻击；两者同时合格时选择水平距离更近者，平局选择Player。
- 蓄力开始后锁定发射方向，不继续追踪目标。目标移动、消失或镜像被回收不会取消本次发射。
- 火球保持水平、固定速度运动；不受重力，不转向、不追踪、不产生爆炸、点燃、熔化或持续燃烧。
- 火球命中实体阻挡后销毁；命中Player触发完整房间重置，命中MirrorClone只触发镜像死亡和镜子回收。
- 火球不破坏镜子、不触发机关、不推动动态对象，也不修改Tilemap。
- 例外：显式配置为`FireballLatch`模式的`PressurePlate2D`可以被水平火球命中并锁存激活；火球随即销毁。普通`Occupancy`压力板仍不响应火球。
- 火球直接命中关闭的门仍然销毁，不能把门当作开关，也不能绕过门的显式控制源。
- 火球未命中时，在离开相机可显示边界`1 unit`或存活`2 seconds`时销毁，以先发生者为准。
- 蓄力与发射使用本体、发射口动画和声音反馈，不显示红色小叉、准星或落点标记。
- 统一数值、Prefab、重置和完整行为见`docs/systems/HORIZONTAL_FIREBALL_ENEMY_PROPOSAL.md`；该文档中的已确认提案值作为首版实现规则。
- 该机制尚未获准进入具体正式房间。安排教学房前必须更新地图、区域房间索引与对应房间设计文档。

### 巡逻投火者

- 正式玩法名称：巡逻投火者；计划实现名称：`PatrollingHorizontalFireballEnemy2D`。
- 它是独立敌人原型，不是`HorizontalFireballEnemy2D`的房间开关或Prefab Variant；原固定投火者行为保持不变。
- 继承水平投火者的攻击带、目标选择、蓄力锁定、水平火球、伤害、镜子交互和投射物生命周期规则。
- 敌人在连续安全`StaticSolid`地面上以`1.5 units/s`水平巡逻；遇到由Tilemap或独立Collider提供的`StaticSolid`前方阻挡，或前脚失去有效安全地面时，停止`0.2 s`并反向。
- `Windup`和`Cooldown`期间停止巡逻；蓄力开始后发射方向保持锁定，转向请求只能在恢复巡逻前结算。
- 巡逻与阻挡查询不得依赖Tile、Sprite、Tilemap、GameObject、Layer或房间名称，也不得运行时修改Tilemap。
- 完整规则见`docs/systems/PATROLLING_HORIZONTAL_FIREBALL_ENEMY_PROPOSAL.md`。
- 通用组件、共享配置、Prefab与独立测试Scene已生成，但尚未进行PlayMode试玩，也未安排正式教学房；加入正式房间前仍须同步地图、火区房间索引和对应房间文档。

## 首批房间教学顺序

- FIRE_001：只教学岩浆。
- FIRE_002：首次教学水平投火者目标选择、狭道限制和MirrorClone替身承伤。
- FIRE_003：顶部放镜后沿左右通道纵向分流，组合两段持续占用的交叉压力板门；当前手工灰盒不使用投火者、火球锁存、永久双压力板门控组、岩浆或周期喷发。
- FIRE_004：小型火球机关门房；用MirrorClone改变水平投火者的发射方向，让火球命中`FireballLatch`并锁存打开出口门；灰盒已完成，待试玩。

## 与镜子机制的关系

火区标准`Hazard` Tilemap中的固定岩浆统一使用`Assets/Art/Generated/Fire/Fire006LavaTile.png`作为可见Tile图像；该视觉统一不改变各房间的危险范围、Collider、伤害、镜子交互或重置规则。

火元素必须与核心镜子机制发生有意义的互动，而不只是作为障碍物。

可探索的组合包括：

- 玩家与镜像分别站在不同位置，同时避开岩浆。
- 镜像穿过危险区域，替玩家触发远处机关。
- 镜子只能放置在已经冷却的表面上。
- 热流改变镜像的移动方向或可到达区域。
- 玩家控制火焰状态，为镜像创造通路。
- 镜子放置后成为需要保护的位置。
- 收回镜子会导致镜像消失，也会使其正在维持的机关失效。

新增互动前，必须明确它是否属于区域规则，不能只为单个房间临时改变镜子行为。

当前已批准的岩浆与周期喷发都不破坏镜子。未来若设计“危险物破坏镜子”的房间，必须先把该危险作为独立区域机制批准，明确视觉标识、作用范围和重置规则，并同步更新镜子机制文档与测试。

## 房间规模规划

约50个房间可以按以下功能初步分配：

- 5个区域引入和氛围房
- 10个单机制教学与练习房
- 15个机制变化房
- 10个镜子组合房
- 5个高难或可选挑战房
- 4个综合考验房
- 1个区域终局房

这只是初始规划，可以根据测试结果调整。

## 难度发展

### 第一阶段：认识火

玩家学习：

- 岩浆不可直接通过
- 火焰和喷发具有可预测状态
- 安全地面与危险地面具有明确区别

### 第二阶段：控制火

玩家学习：

- 点燃机关
- 阻断或改变火焰传播
- 冷却岩浆
- 利用热流

### 第三阶段：火与镜像

玩家需要协调玩家、镜子和镜像的位置，并利用火元素打开路径。

### 第四阶段：机制组合

组合火焰传播、周期喷发、热流、冷却表面和镜像机制，但每个房间应具有一个清晰的主要洞察。

### 第五阶段：精通

减少显式教学，让玩家根据此前建立的规则独立解决综合谜题。

## 房间设计要求

每个房间必须记录：

- 房间编号和名称
- 所属区域阶段
- 教学目标
- 使用的机制
- 初始状态
- 预期洞察
- 预期解法
- 常见错误解法
- 是否存在软锁
- 重置方式
- 潜在逃课解法
- 预计完成时间
