# 中央区域

## 区域定位

Center是游戏教学区，负责用最少视觉噪声建立Player、镜子、MirrorClone、入口、出口和基础机关的统一识别规则。具体建筑与自然环境主题仍待后续确认。

## 环境视觉分层

Center采用全局受《LIMBO》启发的摄影化多层剪影视觉母语，并必须使用`docs/systems/ENVIRONMENT_VISUAL_SYSTEM.md`的标准八层结构和默认视差倍率。层级内容依次为：中性柔雾光底、极远简洁轮廓、远处建筑或自然环境、中景教学空间结构、后部薄雾、玩法地形与角色、前部低密度尘埃、克制的深色边缘框景。玩法层不使用视差。

Center的正式色彩、环境对象和区域造型仍待确定；在这些决定获批前，可以使用中性灰与低饱和柔光进行灰盒视觉验证，但不得套用火、雪、土或风区的专属元素。
