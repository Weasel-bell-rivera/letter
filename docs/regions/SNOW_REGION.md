# 雪之区域

## 区域相机规则（已确定）

- 所有正式雪区房间统一使用`CameraFollow2D`跟随运行时生成的Player；MirrorClone、Enemy和机关不得成为跟随目标。
- 正交尺寸统一为`7`，水平与垂直跟随均启用，平滑时间统一为`0.15秒`。
- 每个房间必须显式配置相机可显示边界；完整视野不得越过该边界。
- 当房间在某一方向不大于完整视野时，该方向按通用相机规则居中固定；这仍属于有边界的Player跟随模式，不得为制造移动而显示房间外内容。
- Player死亡、手动重置和重新进入房间时，相机必须清除追踪速度并回到当前入口或检查点对应构图。
- 雪区沿用通用的四方向入口接管规则：左右入口以水平中央线接管，上下入口以Player位于画面从上向下`54%`的构图线接管，水平与垂直轴独立判断；不得保留出生侧的永久跟随偏移。
- 该区域统一尺寸是经过批准的区域构图参数；雪区房间文档不得继续声明为固定单屏或使用其他正交尺寸。

## 区域边界

- 雪区场景统一表现为地表以上的开放空间；正式雪区房间不设置包围房间的左右外墙或顶部墙。
- 房间内部因平台支撑、确定性刹停、门体封闭或谜题分隔所需的局部竖墙仍可使用，但不得延伸成包围整个房间的外框。
- 移除外墙不改变相机显示边界、入口出口触发、重置或场景切换规则；相机边界之外使用统一雪区背景延伸，不通过实体墙定义可显示范围。
- 雪区不使用`SpecialMirrorWall`；雪区房间不得配置特殊墙面镜或依赖旋转重力MirrorClone作为解法。
- `SpecialMirrorWall`当前只用于风区。雪区仍可在普通合法地面使用通用地面镜，但具体房间是否要求镜子以房间文档为准。

## 区域定位

雪之区域以“预测角色与镜像在哪里停下”和“改变敌人的冻结位置”为核心解谜语言。区域规则必须保持确定、可观察和可重复，不通过随机打滑、随机敌人行为或极短操作窗口制造难度。

当前已批准的首版机制为：

- 静态寒冰地面。
- Player进入寒冰后的首格渐冻死亡，以及MirrorClone的低摩擦效果。
- 静态冻结地面；角色接触后逐渐减速并累积冻结，完全冻结时按角色类型结算死亡或冻结。
- 可冻结地面巡逻敌人。
- 敌人脚部稳定接触寒冰地面后在首次接触格内逐渐冻结，并在格中心成为安全踏板。
- 通过固定路线、门、压力板或移动对象改变敌人到达寒冰地面的时机与位置。
- 同房间临时胡萝卜与雪人挡路机关。
- 固定周期的区域落雪危险与静态地形遮蔽。

## 雪人与临时胡萝卜（已确定）

- 胡萝卜属于`TemporaryPickup`，只在所在房间的当前尝试有效，不写入存档，也不跨房间携带。
- 只有Player可以拾取胡萝卜；MirrorClone不能拾取或交付。
- Player接触胡萝卜后立即把它交付给本房显式引用的雪人，雪人关闭实体阻挡并显示满足状态。
- Player死亡或手动重置时，胡萝卜回到初始位置并恢复可拾取状态，雪人恢复挡路。
- 场景切换不携带胡萝卜或雪人状态。
- 胡萝卜和雪人使用通用Prefab与显式引用，不得按对象名称或房间编号查找配对。

## 周期落雪（已确定）

- 周期落雪按固定`预警 → 危险 → 冷却`顺序循环，首版默认时长分别为`1.5s`、`1.25s`和`2.5s`。
- 危险区域和静态遮蔽物必须在行动前清楚可见；落雪不随机提前、不追踪角色，也不改变周期时长。
- 危险阶段接触Player执行完整房间死亡重置；接触MirrorClone只执行镜像死亡与镜子回收。
- 落雪不伤害或推动Enemy，不改变门、压力板、镜子或冻结敌人状态，不生成、删除或修改Tilemap。
- 手动重置和Player死亡后从预警阶段重新开始；MirrorClone单独死亡不重置周期。
- 场景切换不携带落雪相位或计时。

首版不批准运行时生成、删除、破坏、融化或冻结Tilemap，也不批准随机追踪敌人、限时自动解冻、半空冻结或冻结敌人堆叠。

## 冻结地面

### 与寒冰地面的区分

- `FreezingGround`是新增的独立静态表面语义，不替代`FrozenGround`。
- `FrozenGround`为Player提供首格渐冻死亡，为MirrorClone提供低摩擦滑行，并使可冻结地面巡逻敌人在首个接触格内逐渐冻结。
- `FreezingGround`负责逐渐减速、冻结累积、普通地面恢复和完全冻结结算。
- 两种表面必须使用可清楚区分的视觉语言，不得仅靠Tile、Sprite、GameObject或Tilemap名称决定玩法行为。

### 接触、累积与逃脱

- Player、MirrorClone和所有Enemy都具有统一的冻结累积能力；具体房间可以通过布局避免某类Enemy接触，但不得让该Enemy缺少通用资格。
- 任一参与对象的实体Collider首次接触`FreezingGround`时立即开始累积冻结，不要求脚部稳定着地；侧面、头部或落地接触都有效。
- 首次有效接触同时锁定本次冻结过程的目标格；目标格是其Collider最先接触到的`FreezingGround`格子。
- 冻结累积期间，对象沿自身主动运动方向逐渐减速；Player和MirrorClone仍可跳跃逃脱，跳跃、重力、土狼时间和跳跃缓冲不因冻结累积改变。
- 离开`FreezingGround`进入空中时，当前冻结量保持，不继续增加也不恢复。
- 再次接触`FreezingGround`时继续增加同一次冻结过程，不更换已经锁定的目标格。
- 落到普通、安全、可站立地面后冻结量逐渐恢复；恢复到零时清除已锁定目标格，下一次接触可以锁定新格子。
- 完全恢复前再次接触`FreezingGround`时停止恢复并继续累积。
- 首版不处理两个对象竞争同一目标格的特殊仲裁；关卡布局应避免依赖该情况。

### 完全冻结

- 冻结量达到上限时，对象沿冻结地面切线吸附到已锁定格子的中心；水平地面只修正世界X，不把对象中心移入Tile内部。
- 吸附前必须保留实体碰撞安全，不得穿入墙、门或其他实体Collider；目标位置被占用时保持当前安全位置并继续完全冻结结算。
- Player完全冻结视为死亡：清空运动并进入完整房间死亡重置。
- MirrorClone完全冻结视为镜像死亡：立即清理交互占用、销毁MirrorClone并自动回收镜子，不重置整个房间。
- Enemy完全冻结：停止当前运动和AI阶段、清空速度、关闭伤害并保持实体Collider；冻结状态持续到手动重置、Player死亡重置或场景切换。
- Enemy冻结后默认是安全动态对象，但只有原本明确批准为可站立平台的敌人继续提供安全踏板；不得因通用冻结自动把飞行或墙面敌人变成平台。

### 统一参数

- 冻结累积速度、普通地面恢复速度、最低主动运动倍率和中心吸附速度由雪区统一运行时配置提供。
- 首版原型默认值分别为：`0.5/s`、`0.75/s`、`0.2`和`8 units/s`。
- 房间Scene不得覆盖这些数值；后续手感调整必须同步检查Player、MirrorClone和全部Enemy类型并更新本文档。

## 寒冰地面

### 机制定位

寒冰地面是雪之区域的静态安全表面，同时承担以下职责：

- 为MirrorClone提供低摩擦移动效果；移动中的Player稳定踩入后锁定首次接触格并逐渐冻结。
- 使符合冻结资格的活动敌人在稳定踩上表面后进入冻结状态。
- 提供清晰、可预测的冻结位置和刹车空间。

寒冰地面使用统一的`FrozenGround`表面语义。玩法系统不得根据Tile名称、Sprite名称、Tilemap名称、GameObject名称或房间编号判断寒冰规则。

寒冰地面本身不会在运行时生成、消失、损坏、融化、耗尽或改变Tile。移动寒冰平台属于动态玩法对象，必须使用移动平台Prefab实现，不属于静态`FrozenGround` Tilemap。

### 对Player和MirrorClone的影响

- 移动中的Player稳定踩入寒冰时开始逐渐冻结，到首次接触格中心后死亡并回到当前出生点或复活点。
- 静止站在寒冰上的Player不会凭空选择方向或开始冻结；一旦沿寒冰移动便锁定该方向的首次接触格。
- MirrorClone仍不会被`FrozenGround`冻结，继续沿用低摩擦滑行规则。
- Player与MirrorClone接触同类寒冰地面时使用不同结果明确的统一规则：Player首格渐冻死亡，MirrorClone低摩擦滑行。
- 寒冰地面只改变沿接触表面切线方向的运动，不改变角色Collider或局部重力。
- 寒冰地面不改变最高移动速度、跳跃高度、土狼时间、跳跃缓冲或最大下落速度。
- MirrorClone离开寒冰地面后恢复默认移动参数；Player已锁定的首格渐冻不会因短暂离地取消。
- 同类寒冰地面的运动参数由雪区统一配置，不得在具体房间中覆盖。

| 参数 | 当前状态 |
|---|---|
| 寒冰地面加速度 | 0 units/s² |
| 寒冰地面减速度 | 0 units/s² |
| 最高移动速度 | 沿用默认移动参数 |
| 空中控制 | 沿用默认移动参数 |

MirrorClone在寒冰上的当前切向速度保持不变：输入不会使其沿表面加速、反向或主动刹车，松开输入也不会减速。Player开始寒冰渐冻后保持进入方向，并按进入点到目标格中心的距离连续减速到最低`25%`进入速度；抵达或越过格中心时吸附到中心、清空运动并执行Player死亡重置。渐冻期间即使短暂离地也不取消已经锁定的冻结结果。

### 对敌人的影响

具有`Freezable`资格的活动敌人，在脚部稳定接触`FrozenGround`表面后进入逐渐冻结状态，并在首次接触格中心完全冻结。

- 敌人身体侧面接触寒冰墙壁不会冻结。
- 敌人头部接触寒冰天花板不会冻结。
- 只有冰雪外观、不带`FrozenGround`语义的背景或装饰不会冻结敌人。
- 寒冰地面只提供表面语义，不直接管理或保存敌人实例。
- 寒冰地面不因成功冻结敌人而改变状态。

敌人的巡逻、伤害、冻结状态、平台化、重置和场景切换规则以`docs/systems/ENEMY_SYSTEM.md`为准。

### 与镜子的关系

- 静态、水平、安全且空间充足的寒冰地面允许放置镜子。
- 镜子成功放置后保持固定，不受寒冰低摩擦效果影响。
- 寒冰地面上的镜像生成空间仍须通过通用合法性检查。
- 寒冰墙壁不是特殊镜墙，不能仅因具有寒冰外观而安装镜子。
- 冻结敌人和移动寒冰平台属于动态表面，不能放置镜子。

## 可冻结地面巡逻敌人

- 敌人在房间配置的左右端点之间水平来回巡逻。
- 敌人到达端点后短暂停顿并转向。
- 敌人不随机改变方向，不追踪Player或MirrorClone。
- 敌人不跳跃、不飞行、不攀墙，也不主动走下平台边缘。
- 敌人被墙阻挡时停止并转向，不能持续挤压角色。
- 敌人脚部稳定接触`FrozenGround`后锁定首次接触格，继续向当前方向移动并逐渐减速、逐渐结冰；抵达该格中心时完全冻结、停止巡逻并成为安全踏板。
- Player死亡或手动重置后，敌人回到初始位置、初始方向和活动状态。
- MirrorClone单独死亡不会重置敌人。

具体通用规则见`docs/systems/ENEMY_SYSTEM.md`。

## 教学房型示例：冻结台阶

本节记录一个不绑定具体房间编号的标准教学房型。世界访问顺序与正式房间分配仍须结合`docs/maps/WORLD_PROGRESSION.md`和房间连接另行批准。

```text
                                  #### X
                                  ######
S   P               E ->      III######
=================================######
```

图例：

- `S`：安全入口。
- `P`：Player初始位置。
- `E`：活动巡逻敌人。
- `I`：`FrozenGround`静态寒冰地面。
- `#`和`=`：`Terrain`静态地形。
- `X`：高台出口。

预期流程：

1. Player在安全位置观察敌人沿固定路线巡逻。
2. 敌人从普通地面稳定走上寒冰地面。
3. 敌人进入冻结状态并停止造成伤害。
4. Player踩上冻结敌人的顶部。
5. Player从冻结敌人跳上右侧高台并抵达出口。

房型要求：

- 本房型只教学“敌人踩冰冻结”和“冻结敌人可以踩踏”。
- 不把镜像、压力板、门、移动平台或其他雪区机制设为通关要求。
- 寒冰区域应足够短，使敌人在首次接触边界冻结后仍位于高台的可靠标准跳跃范围内。
- 入口、敌人路线、寒冰地面、预期冻结位置和高台必须能被同时观察。
- 投入正式房间前必须根据`docs/maps/MAP.md`确认房间编号、相邻房间和出口方向，并在对应房间文档获得批准。

## 重置与场景切换

寒冰Tilemap是静态地形，不参与运行时重置，也不改变Tile内容。

手动重置或Player死亡时：

- 寒冰Tilemap保持不变。
- 冻结敌人恢复活动状态并回到房间配置的初始位置、方向和巡逻阶段。
- Player和MirrorClone清除寒冰表面运动状态。
- 镜子和镜像按`docs/systems/RESET_SYSTEM.md`恢复。

场景切换时不携带敌人冻结状态、巡逻阶段或寒冰表面运动状态。

## 视觉与反馈

- 寒冰地面的可见边界、实体碰撞边界和`FrozenGround`语义边界必须一致。
- 活动敌人应使用持续移动和活动轮廓；冻结敌人应具有坚硬、稳定且顶部可站立的清晰轮廓。
- 冻结瞬间至少提供结霜视觉和一次明确声音反馈。
- 只有冰雪外观、不参与玩法的Tile必须放在无碰撞的背景或装饰层，不能伪装成`FrozenGround`。
- 玩家在行动前应能分辨普通地面、寒冰地面、活动敌人和冻结敌人。
- Player、MirrorClone和Enemy统一使用`FreezingVisual2D`读取`FreezingGroundActor2D.FreezeAmount`；表现组件不得自行累积冻结、修改移动或决定完全冻结结果。
- 冻结量增加时，角色Sprite逐渐转为冰蓝并叠加半透明霜层；达到`75%`后霜层产生高频轻微脉冲，提示即将完全冻结。
- 落到普通安全地面并恢复时，染色与霜层按同一冻结量连续消退；手动重置、Player死亡和场景切换不得留下残余表现。
- MirrorClone保留原有半透明度与最后渲染层，冻结表现只在其基础颜色上叠加，不改变镜像辨识规则。

## 验收标准

- Player接触寒冰地面后按首格渐冻死亡，MirrorClone保持低摩擦滑行，两者反馈必须能被预判和区分。
- 可冻结敌人只在脚部稳定接触`FrozenGround`后开始冻结，并在首次接触格中心完全冻结。
- 敌人侧面或头部接触寒冰不会冻结。
- 冻结敌人停止伤害并可被双方稳定踩踏。
- 静态水平寒冰地面在满足空间条件时允许放置镜子，镜子不会滑动。
- 冻结敌人和移动寒冰平台不能作为镜子放置表面。
- 修改Tile、Sprite或GameObject名称不会改变寒冰和冻结结果。
- 手动重置、Player死亡和场景切换不会留下敌人冻结或寒冰运动残留状态。
