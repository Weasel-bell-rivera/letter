# 风柱与小龙卷风系统

## 状态与权威范围

- 当前状态：首版规则已确认，通用运行时代码与Prefab已创建；PlayMode与人工试玩未执行。
- 本文定义风柱、移动小龙卷风、生产器、门阻挡、角色交互、重置和场景切换规则。
- 区域归属：风之区域。
- 固定在网格中的一格小龙卷风继续使用标准`Hazard` Tilemap；只有运行时移动的小龙卷风使用Prefab。

## 风柱

### 视觉表现

- 风柱不得只用一张纯色矩形表达。纯色只允许作为低透明度风域底雾，实际吹风状态必须由可辨认的流线、卷曲风纹和方向条纹共同表现。
- 风柱使用两层透明风纹：远层较淡、移动较慢，近层更亮、移动幅度和呼吸频率更高；两层统一沿实例的世界风向旋转。
- 常吹和周期`Blowing`状态使用青白色高速流线；周期`Warning`状态使用仍在移动的青白手绘流线，仅在近层加入脉冲式暖色高光，不允许出现黄色实心矩形；`Calm`状态保留极淡残余气流，使玩家仍能辨认风柱范围和方向，但不得误读为正在施力。
- 风纹动画只属于表现层，不参与碰撞、风速、遮挡、周期计时或重置判断。
- 风区房间背景使用低对比度青蓝天空、远云、浮岛剪影和大尺度风带；背景排序必须位于Tilemap、角色和机关之后，不得遮盖可交互对象。
- 首版美术资源：`Assets/Art/Wind/Effects/wind_streaks_v1.png`与`Assets/Art/Wind/Backgrounds/wind_region_sky_v1.png`。

### 统一行为

- 风柱是显式配置方向和范围的Trigger区域，不根据Tile、名称或房间编号推断。
- Player和MirrorClone受到完全相同的世界空间风速；镜面输入变换、镜像重力方向和失重状态不改变风向。
- 风柱把角色沿风向的速度至少提升到配置风速，不覆盖垂直于风向的速度，也不持续无限加速。
- 角色原本沿风向速度更快时不减速；逆风进入时稳定转为顺风目标速度。
- 风柱不推动敌人、门、镜子、移动平台或其他动态物体。

### 模式与首版数值

| 参数 | 首版默认值 | 允许范围 |
|---|---:|---:|
| 风速 | `4 units/s` | `1～8 units/s` |
| 常吹模式 | 始终吹风 | 不适用 |
| 周期预警 | `0.5 s` | `0.2～2 s` |
| 周期吹风 | `2 s` | `0.5～6 s` |
| 周期停风 | `1.5 s` | `0.5～6 s` |

- 周期固定为`Warning → Blowing → Calm → Warning`，不使用随机数。
- 预警必须显示方向和即将启动的反馈，但不施加风速。
- 手动重置、Player死亡重置和重新进入房间恢复实例配置的初始状态及完整初始计时。

### 遮挡

- 风柱对每个角色从风柱来风方向的上游边界向角色执行实体遮挡查询；不得从区域中心取样，因为垂直风柱中心可能位于平台内部并错误阻断整列风。关闭的门和真正位于上游边界与角色之间的静态实体地形阻挡风。
- 门开启或处于防夹等待的实际开启状态时Collider禁用，风可以通过门洞。
- 风柱不得根据`Door2D`名称判断；实际启用的非Trigger实体Collider是阻挡权威。

## 移动小龙卷风

- 使用Kinematic`Rigidbody2D`和Trigger伤害轮廓，沿显式世界方向匀速移动。
- 默认速度`3 units/s`，允许范围`1～6 units/s`；默认最大路程`12 units`，允许范围`1～30 units`。
- 命中Player时触发完整房间重置。
- 命中MirrorClone时只执行镜像死亡和镜子回收。
- 命中角色后该枚小龙卷风消失；不得在同一物理步重复伤害两个角色。
- 小龙卷风碰到关闭的门、普通墙壁或其他静态实体Collider时，该枚小龙卷风立即消失；不得停在阻挡前等待，也不会在阻挡解除后继续移动。
- 已批准的`WindDeflector2D`是实体阻挡中的唯一重定向例外：匹配输入方向时按导风板规则改变方向并继续移动，不触发碰墙消失。
- 达到最大路程后消失，不反向、不循环，也不寻找其他路线。
- 小龙卷风不触发压力板、不破坏镜子、不推动角色，也不是镜子放置表面。

## 小龙卷风生产器

- 生产器显式引用`MovingTornado2D.prefab`，不得根据资源名查找。
- 默认每`2 s`生成一枚，同时存在上限`3`；生成间隔允许`0.5～10 s`，上限允许`1～8`。
- 生产器使用自身Transform位置作为显式出生Pose，生成方向由序列化世界方向配置。
- 出生空间被实体Collider、Player、MirrorClone或其他小龙卷风占用时，本次生成取消；不挤开对象、不改用其他点。
- 手动重置和Player死亡重置立即停用并清除全部在途小龙卷风，恢复完整初始生成间隔。
- MirrorClone单独死亡和镜子回收不重置生产器或其他在途龙卷风。
- 场景切换清除旧房间实例和延迟生成状态。

## 导风板

- 导风板接收一个显式配置的世界空间来风方向，并将有效气流固定旋转`+90°`或`-90°`。
- 首版只有顺时针与逆时针两种稳定朝向，不支持自由角度、随机方向、分流或改变风速。
- 导风板具有实体阻挡轮廓：原风柱在板后形成风影；被导出的风只作用于显式配置的输出Trigger范围。
- 导风板只有在来风方向匹配、对应风柱处于实际吹风状态且风源到板之间无遮挡时输出风。
- 输出风速继承输入风柱，不叠加、不倍增；Player与MirrorClone受到完全相同的世界空间输出风。
- 导风板可以显式引用一块普通压力板：未激活使用实例初始朝向，激活时切换到另一朝向；没有控制源时保持初始朝向。
- 手动重置、Player死亡重置和重新进入房间恢复初始朝向；MirrorClone死亡或镜子回收只通过压力板占用清理间接影响它。
- 移动小龙卷风撞到方向匹配的导风板时按当前朝向转`90°`并继续，速度、剩余生命周期和伤害规则不变。
- 来向不匹配时导风板作为普通实体阻挡小龙卷风。
- 首版不支持一个导风板的输出继续驱动第二个导风板；需要串联时必须先扩展确定性的风路模型。

## 风力涡轮机关

- 风力涡轮是持续型风信号接收器，不产生风、不储存能量，也不改变风向或风速。
- 每个实例显式配置一个接受方向；只有方向匹配、实际处于吹风状态且无遮挡的直接风柱或导风板输出风能够激活。
- 周期风柱只在`Blowing`阶段激活涡轮；进入`Warning`或`Calm`后涡轮立即释放。
- 小龙卷风、Player、MirrorClone、敌人和其他动态物体不能激活涡轮。
- 涡轮可以显式引用一扇普通`Door2D`：有风时请求开门，失风时请求关门；门继续使用通用防夹规则。
- 涡轮控制的门初始必须关闭，且不得同时配置压力板或永久锁存控制源，避免多个控制源竞争。
- 涡轮同时提供通用`ActiveChanged`事件，后续批准的接收器可以显式订阅；首版Prefab不自动搜索目标。
- 手动重置、Player死亡重置和重新进入房间恢复未激活状态；下一固定物理步根据当前实际风路重新结算。
- 涡轮使用Trigger接收区，不阻挡风、角色或小龙卷风，也不是镜子放置表面。

## 最小验证要求

- Player与MirrorClone在同一风区获得相同世界空间风速。
- 周期状态与重置确定且不依赖渲染帧率。
- 关闭门阻挡风与小龙卷风，门开启后恢复通行。
- Player与MirrorClone分别触发完整重置和镜像死亡流程。
- 生产器遵守生成间隔、数量上限、出生占用和统一重置。
- 场景切换不留下旧龙卷风或延迟生成。
- 导风板只接受匹配来向，正确形成风影和`90°`输出，并在重置时恢复初始朝向。
- 风力涡轮只响应匹配且无遮挡的持续风，失风立即释放，并保持门控制源唯一。
