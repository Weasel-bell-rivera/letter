# 门与压力板系统

## 压力板

- PressurePlate采用持续占用逻辑：至少一个满足条件的对象站在上面时保持激活，对象全部离开后恢复未激活。
- 首版允许Player和MirrorClone触发，动态物体不能触发。
- 镜像消失或死亡时必须立即从压力板占用列表移除。
- 压力板必须提供清晰的按下、保持和弹起反馈。

## 门

- 门由一个或多个压力板或Trigger控制。
- 单压力板控制时，压力板激活则开门，压力板释放则关门。
- 多压力板控制支持AND和OR配置，默认使用AND。
- 房间文档必须明确每扇门的控制源、逻辑模式和初始状态。

### 控制源唯一性（已确定）

- 门的逻辑目标状态只能由房间中明确配置的开关控制源（压力板或已批准的Trigger）、永久锁存状态以及统一重置初始化流程决定。
- Player、MirrorClone、敌人或其他动态对象与门体的碰撞、接触和重叠检测都不是开门信号，不得改变门的逻辑目标状态、视觉状态或锁存状态。
- 已完全关闭的门被Player、MirrorClone或敌人从外侧碰到时，必须继续保持关闭表现和实体阻挡；接触不得使门开启、变色或禁用Collider。
- 防夹检测只负责延迟执行已经收到的关闭命令，不是门的控制源，也不能生成开启命令。
- 具体房间可以限制哪些对象能够到达开关，但不得把“对象碰门”作为任何门的隐藏控制方式。

## 永久锁存双压力板门控组（已确定）

永久锁存双压力板门不是三个独立机关，而是一个完整的门控机关组。每组包含一扇门、两块压力板和一个稳定且全游戏唯一的`DoorGroupId`；具体房间文档必须记录组ID、门ID、两块压力板ID、初始状态和空间位置。

锁存前按两块压力板的激活数量结算：

| 激活的压力板数量 | 门状态 | 压力板状态 |
|---:|---|---|
| 0 | 关闭 | 两块均弹起 |
| 1 | 临时开启；该压力板释放且另一块未激活后恢复关闭 | 被占用的压力板按下 |
| 2 | 机关组立即进入永久锁存状态 | 两块压力板永久保持按下 |

- Player和MirrorClone都可以触发压力板；动态物体不能触发。
- 每块压力板只输出“激活”或“未激活”状态。同一块压力板上存在多个有效对象时仍只计为一块压力板激活；直到最后一个有效对象离开才恢复未激活。
- “两块同时激活”是指在同一次物理状态结算中，两块压力板都处于激活状态。可以先持续踩住一块，再踩下另一块，不要求两个对象在同一帧进入。
- 每个物理状态结算先更新两块压力板的占用状态，再统一结算机关组状态；不得让Trigger回调顺序影响锁存结果。
- 锁存发生后，门永久保持完全开启，两块压力板永久保持按下；后续对象离开、MirrorClone死亡或消失、镜子回收或被破坏都不能解除锁存。
- 锁存状态跨手动重置、玩家死亡、房间切换、重新进入房间、退出游戏和存档读取保留，只有开始新存档才清除。
- 锁存时必须立即把`DoorGroupId`提交给统一存档服务；Scene对象不得直接写入存档文件。
- 读取到已锁存的`DoorGroupId`时，机关组直接初始化为门完全开启、两块压力板保持按下的状态，不重播首次锁存流程。
- 即使机关组已经锁存，压力板仍必须清理MirrorClone等对象留下的占用引用，但占用变化不再改变门或压力板的锁存表现。
- 临时开启与永久锁存必须提供可区分的视觉和声音反馈，玩家应能判断机关是否已经永久完成。
- 该规则必须由通用门控组件实现，不得写死在具体房间脚本中。
- 压力板与门之间不绘制实体连线。因果关系通过压力板按下状态、门的开启状态、锁存色调、声音以及关卡空间布局表达。

## 防夹安全

- 防夹只在门原本处于开启状态，并且已配置控制源随后请求关闭时生效。
- 收到关闭请求后，门的逻辑目标状态已经是关闭；若Player、MirrorClone、活动敌人、冻结敌人或逐风鳐实际占用门的关闭路径，则暂缓应用关闭表现与实体阻挡。
- 对象离开后，门继续完成同一次关闭命令；防夹等待不得把逻辑目标状态改回开启。
- 已完全关闭的门不运行“受阻则保持开启”的分支。对象从门外侧接触关闭门的边界不算占用关闭路径，不能触发防夹。
- 门不得压死、推出、穿过或永久困住角色或敌人。
- 门在关闭过渡被占用而等待期间保持开启表现和无阻挡状态；这只是关闭命令的物理执行延迟，不代表控制源重新请求开启，也不改变敌人的活动、冻结、目标、攻击阶段或伤害状态。
- 房间设计必须把敌人的目标冻结位置放在门关闭范围之外，避免冻结敌人永久占用门路径。
- 关闭的门阻挡逐风鳐的感知和冲刺；逐风鳐返回守卫点时被关闭的门阻挡则原地等待，门重新开启后继续返回。
- 房间重置严格遵循 `docs/systems/RESET_SYSTEM.md` 的统一执行顺序。

## 几何与表现（已确定）

- 通用门由上下两张状态图组成，每张图保持一个标准`1 unit`地形格的纵向比例，整扇门固定为两个格子高，不得为填满门洞拉伸Sprite或Collider。
- 门的标准实体Collider为`0.75 × 2 units`，与两格门体对齐；房间不得通过实例覆盖把门改成更高的隐藏阻挡。
- 需要阻止Player或MirrorClone从门上方绕过时，门洞剩余部分必须使用标准`Terrain` Tilemap静态墙封闭，优先放在门上方。
- 静态墙始终存在，门只负责自身两个格子的开启、关闭、控制、防夹和重置状态；不得把门洞墙体加入门Prefab或随门一起消失。

## 重置

- 手动重置、死亡重置和重新加载房间时，门与压力板恢复房间定义的初始状态。
- Trigger和压力板的占用列表必须清空，不能保留已销毁对象引用。
- 上述恢复规则只适用于普通门控机关和尚未锁存的双压力板门控组；永久锁存组按存档状态恢复为门开启、两块压力板保持按下。
