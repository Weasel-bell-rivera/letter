# 环境视觉分层与视差系统

## 状态与适用范围

- 当前状态：已确定。
- 适用于Center、风、火、雪、土区域的正式环境表现和视觉测试Scene。
- 全游戏采用受《LIMBO》启发的摄影化多层剪影视觉母语；各区域只通过色彩、轮廓、环境内容和动态节奏形成差异。
- 本系统只负责装饰层、视差和氛围，不改变Tilemap、Collider、表面语义、镜子、镜像、危险或机关规则。

## 标准八层结构

| 层级 | 职责 | `cameraFollowFactor` |
|---|---|---:|
| 1. 最远处颜色/雾光底 | 全画面基础色、最远雾光和主明暗分布 | `1.00` |
| 2. 极远景轮廓 | 最低对比的大型天际线、洞壁或区域轮廓 | `0.95` |
| 3. 远景环境 | 可辨认但雾化的远处环境结构 | `0.85` |
| 4. 中景环境 | 玩法层后方的主要环境模块 | `0.65` |
| 5. 后部动态雾 | 位于玩法层之后的缓慢雾、烟、雪或尘层 | `0.80` |
| 6. 玩法地形与角色 | Tilemap、动态Prefab、Player、MirrorClone和玩法反馈 | 不使用视差 |
| 7. 前部动态雾/粒子 | 位于玩法层之后、最前景之前的低密度动态表现 | `0.35` |
| 8. 最前景遮挡 | 画面边缘框景和最近环境剪影 | `0.20` |

`cameraFollowFactor`沿用`ParallaxLayer2D`的现有定义：相机移动`1 unit`时，该层在世界空间跟随的距离。数值越接近`1`，该层相对屏幕越稳定并显得越远；玩法层不挂载`ParallaxLayer2D`。

## 统一实现规则

- 默认仅跟随相机水平位移；房间确需纵向视差时必须在房间文档中说明，不能自行改变倍率。
- 八层是功能层，不等于八张整房图片；每层可以由多个可复用Sprite、Tile、粒子或表现模块组成。
- 最远处颜色/雾光底可以使用覆盖相机视野的底图；第2～4层必须能够独立排序和移动，正式房间不得把完整可玩布局烘焙进背景。
- 后部与前部动态雾必须分属玩法层两侧，不能使用一张全屏不透明雾同时覆盖全部景深。
- 所有装饰层不得包含Collider、Trigger、表面语义或玩法脚本，也不得根据层级名称推断玩法规则。
- 房间可以省略没有内容的视觉层，但不得把相邻层合并后宣称已经实现独立视差；临时概念底图中烘焙的层必须明确标记为待拆分。
- 区域或房间如需偏离默认倍率，必须记录原因、实际倍率和对相机边界的影响；不得逐对象随意调参。

## 区域内容映射

- Center：中性柔雾、简洁建筑或自然轮廓、低密度尘埃，保持安全和教学感。
- 风区：云海、远山、悬空结构、气流雾带和轻质前景，动态方向以风向为主。
- 火区：岩浆洞穴、烟层、灰烬、热浪和近黑岩壁框景，强调暗红与琥珀熔光。
- 雪区：雾白天际、雪山、冰壁、风雪和深蓝前景，普通飘雪不得与周期落雪危险混淆。
- 土区：暖褐雾光、深井、宽厚岩层、矿井支撑、落尘和近黑洞口框景，强调重量与沉降。

各区域的具体形状、色彩和素材限制仍以对应区域文档为准。
