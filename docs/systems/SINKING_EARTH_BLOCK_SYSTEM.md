# 压沉土块系统

## 状态与范围

- 当前状态：首版规则已确定。
- 适用范围：土之区域的通用动态玩法对象。
- 通用Prefab：`Assets/Prefabs/Gameplay/Earth/SinkingEarthBlock2D.prefab`。
- 首版只实现连续承重、下沉和卸重恢复；不包含永久锁定、多段卡扣、矿石装卸或房间专用事件。

## 核心规则

- 压沉土块拥有初始高度、最大下沉距离、下沉速度、恢复速度和完全下沉所需重量。
- 只有实际接触土块上表面并由其支撑、且具有启用中`Rigidbody2D`的实体计入重量。
- 重量取该实体`Rigidbody2D.mass`，同一实体即使有多个Collider也只计算一次。
- 当前目标下沉比例为`Clamp01(当前重量 / 完全下沉所需重量)`。
- 土块沿世界坐标竖直向下移动，不旋转、不横移、不在运行时缩放。
- 达到或超过完全下沉重量时停在最低高度；额外重量不继续增加行程。
- 重量减少后，土块按恢复速度向初始高度移动；卸重不会永久锁存位置。
- 所有移动使用固定物理步和Kinematic `Rigidbody2D.MovePosition`，不得逐帧直接写Transform。

## Player、MirrorClone与其他物体

- Player与MirrorClone使用相同质量、碰撞和承重规则，不按身份设置不同结果。
- 两者同时站在同一土块上时，各自质量只计算一次并相加。
- MirrorClone被回收、死亡或清除后，其重量在接触解除后立即移除；不会触发整个房间重置。
- 未来矿车或巨石若使用`Rigidbody2D`并由土块上表面支撑，可以通过质量自然参与承重，不需要土块依赖具体类型。
- Trigger、装饰Collider、无`Rigidbody2D`的静态地形和从侧面或下方接触的实体不计重量。

## 表面、镜子和危险

- 土块返回安全、非静态`DynamicSurface`表面语义。
- 土块不是合法镜子放置表面；运动中、停止时和完全下沉时均不允许放置。
- 土块不具有`MirrorSurface2D`，不得通过区域视觉或实例配置改变该规则。
- 土块本身不造成伤害，也不得把角色夹入静态地形。房间必须为完整行程预留角色净空。
- Player和正常重力MirrorClone可站在土块上，并从实际支撑Collider读取同一世界空间表面速度。
- 特殊墙面镜生成的旋转重力MirrorClone仍按自身局部重力判断支撑；仅从侧面接触土块时不计入土块重量。

## 重置与场景切换

- 压沉状态是房间瞬时状态，不写入长期存档。
- 手动重置和Player死亡重置时，清除承重引用、速度和当前重量，并立即恢复初始高度。
- MirrorClone单独死亡或镜子回收只移除对应重量，不重置土块的其他当前状态。
- 场景切换或重新进入房间时加载目标房间Prefab实例的初始高度和配置。
- 土块通过`IRoomResettable`参与统一重置，并在Player传送到复活点前恢复。

## Prefab结构

```text
SinkingEarthBlock2D
├─ Visual
└─ TopMarker
```

根对象必须包含：

- Kinematic `Rigidbody2D`，启用插值、连续碰撞检测并冻结旋转。
- 与可见边界一致的非Trigger `BoxCollider2D`。
- 返回安全、非静态`DynamicSurface`的`SurfaceSemantic2D`。
- 管理承重、移动、表面速度和重置的`SinkingEarthBlock2D`。

房间实例允许覆盖：

- Transform位置，作为初始高度。
- 土块宽度；视觉和Collider必须同步保持一致。
- 最大下沉距离、下沉速度、恢复速度和完全下沉所需重量。
- 不改变碰撞轮廓、表面语义和状态规则的土区视觉。

房间实例不得覆盖：

- Player与MirrorClone的承重资格。
- `DynamicSurface`语义和镜子禁止放置规则。
- 世界竖直下沉方向、统一重置和场景切换规则。
- 将土块改成伤害物、移动门或普通静态Tile。

## 配置与验收

- 下沉距离、下沉速度、恢复速度和完全下沉所需重量必须大于零。
- Scene视图选中对象时必须显示初始位置、最低位置和完整行程。
- 可见轮廓、实体Collider和承重上表面必须一致。
- 相同初始配置和重量序列必须产生相同位置结果，不依赖渲染帧率。
- Player、MirrorClone和通用动态实体按质量产生一致结果，多Collider实体不得重复计重。
- 卸重后能恢复；手动重置、Player死亡和重新进入房间恢复初始状态。
- 镜子放置查询始终拒绝该表面，失败不改变镜子、镜像或土块状态。
