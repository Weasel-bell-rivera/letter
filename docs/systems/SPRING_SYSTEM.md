# 弹簧装置系统

## 状态与权威范围

- 当前状态：首版规则已确定。
- 本文是固定地面弹簧的碰撞、回弹、MirrorClone交互、重置、Prefab配置和测试的权威来源。
- 弹簧是全局通用机关，不属于单个元素区域；区域只能替换不改变玩法边界的视觉和声音。
- 首版弹簧由关卡作者作为固定Prefab实例放在静态水平地面上，不是玩家携带、拾取或自由放置的道具。
- 首版只允许直立朝上，不能旋转、移动、启停、被破坏或接受开关控制。

## 设计目标

1. 玩家在接触前可以从轮廓判断顶面和两侧都会把角色弹离装置。
2. 相同接触始终产生相同回弹结果，不依赖帧率、物理材质弹力、对象名称或房间脚本。
3. Player与MirrorClone遵守完全相同的资格、速度和接触规则。
4. 回弹立即生效且保留可控的切向运动，不锁定输入或强制播放完整动画。
5. 死亡、手动重置、镜像清除和场景切换不留下接触或表现状态。

## 首版规则摘要（已确定）

| 项目 | 已确定规则 |
|---|---|
| 物理形态 | 固定、安全、不可站立的实体装置；根位置是底部中心并贴合静态水平地面 |
| 影响对象 | 只影响Player和MirrorClone |
| 有效面 | 世界坐标顶面、左侧和右侧；底面无效 |
| 顶面输出 | 目标弹射高度`5 Unity units`；按角色当前通用重力大小计算法向初速度 |
| 侧面输出 | 固定`8 Unity units/s`，沿所撞侧面的世界空间外法线 |
| 速度组合 | 法向分量替换为固定输出，切向世界速度保持不变 |
| 最小接近速度 | 朝有效面内侧至少`0.1 Unity units/s`才触发；已经离开表面的接触不触发 |
| 重复触发 | 同一次连续接触最多触发一次；完整离开该角色的全部Collider后才能再次触发 |
| 角点 | 比较接触点到顶、左、右三面的距离；平局时顶面优先 |
| 输入 | 自动触发，不新增Input Action；回弹后立即恢复普通空中控制 |
| Jump状态 | 回弹消费未结算的跳跃缓冲；沿局部反重力方向的弹射不受Jump松开截短 |
| 镜子放置 | 始终不允许；弹簧不具有`MirrorSurface2D`地面资格 |
| 伤害 | 不造成伤害 |
| 重置与存档 | 清除接触和压缩表现，不写入长期存档 |

## 回弹计算

每次有效接触只处理选中的一个面。设选中面的单位外法线为`N`，接触前角色世界速度为`V`，该面的输出速度为`S`：

```text
TangentialVelocity = V - N * Dot(V, N)
ResultVelocity = TangentialVelocity + N * S
```

- 固定输出不会因高速撞击变得更强，也不会继承朝装置内部的法向速度。
- 顶面普通重力角色的输出速度按下式计算：

```text
TopLaunchSpeed = sqrt(2 * CharacterGravityMagnitude * 5)
```

- 当前默认移动配置下该速度约为`22.13 units/s`；Prefab不得复制或覆盖`DefaultPlayerMovement.asset`中的重力数值。
- 顶面回弹保留水平速度；侧面回弹保留竖直速度。
- 回弹发生在固定物理结算路径中，不使用`PhysicsMaterial2D`的Bounciness，不直接改写角色Transform。
- 侧面回弹允许暂时超过普通水平最大速度`6 units/s`；之后由普通空中控制逐步修正，不在触发帧强制裁剪。

## Player与MirrorClone交互

- Player和MirrorClone通过同一个回弹接收接口取得结果，弹簧不得按Layer、名称或身份给出不同数值。
- 弹簧外法线是世界环境方向，不经过镜面输入变换。
- 特殊墙面镜生成的旋转重力MirrorClone仍按实际碰撞的顶、左或右面回弹；只有输出方向与其局部反重力方向一致时才按弹射状态跳过Jump松开截短。
- 双方同时撞击同一弹簧时分别独立结算，不能互相占用全局冷却。
- MirrorClone死亡、镜子回收或镜像清除时，弹簧立即丢弃对应接触记录，不改变Player或装置状态。
- 镜子本身没有实体碰撞，不被弹簧推动、弹射或破坏。

## 镜子放置与表面语义

- 弹簧根对象返回新的显式`Spring`表面语义：固定、安全，但不是普通静态地面、`FrozenGround`、特殊镜墙或移动平台。
- 弹簧Prefab不包含`MirrorSurface2D`，因此站在或接触弹簧时不能把镜子放在弹簧上。
- 弹簧旁的普通地面仍按通用规则查询；弹簧实体Collider占用镜子逻辑边界或MirrorClone生成空间时，放置失败且不改变弹簧状态。
- 禁止根据`spring`文件名、Sprite、GameObject名或房间编号判断放置资格。

## 碰撞与关卡配置

- 根对象使用Static `Rigidbody2D`和非Trigger `BoxCollider2D`；实体Collider与展开状态的可见轮廓一致。
- 首版Prefab宽高均为`1 Unity unit`，根Transform位于装置底部中心，Collider中心为`(0, 0.5)`。
- 弹簧底面必须贴合或略微嵌入静态安全地面，不能悬空、倒置、旋转或与另一实体Collider形成可夹死角色的重叠。
- 房间必须为顶面完整弹射轨迹、两侧回弹空间和预计落点保留完整Player Collider净空。
- 不得把弹簧直接放在不可观察的死亡区前，也不得要求浮点级精确角点触发。
- 多个弹簧可以组合，但重叠Collider、同一位置堆叠或让角色在一个固定步同时进入多个弹簧属于非法房间配置。

## 视觉与反馈

- 展开状态使用`spring_out.png`，压缩反馈使用`spring.png`，均按`128 PPU`、Point Filter、Full Rect和无压缩导入。
- 物理回弹立即发生；视觉在触发时显示压缩图约`0.08秒`后恢复展开，不得用动画事件延迟回弹。
- 多个角色在压缩期间触发仍分别结算；视觉只重新开始同一段短反馈，不形成玩法冷却。
- 展开、压缩图片使用相同画布、Pivot、位置和缩放，切换时底部不得跳动。
- 可选短促音效必须与物理触发同帧开始；没有声音时仍能仅凭形变理解反馈。

## 重置、死亡与场景切换

| 事件 | 弹簧结果 |
|---|---|
| 手动重置 | 清除所有接触记录，立即恢复展开视觉 |
| Player死亡 | 随房间重置清除接触与视觉状态 |
| MirrorClone死亡 | 只清除该MirrorClone的接触记录，不重置装置或Player |
| 镜子回收 | 与MirrorClone清除相同 |
| 场景切换/重新进入 | 不保留接触或压缩计时，加载目标房间Prefab初始展开状态 |
| 读取存档 | 不读取弹簧瞬时状态 |

- 弹簧实现统一`IRoomResettable`；表现组件也必须在重置时恢复展开状态。
- Player重置、传送或MirrorClone销毁时，各自的外部弹射状态必须清除。
- 弹簧没有长期存档字段。

## 技术架构

Prefab路径：

```text
Assets/Prefabs/Gameplay/Devices/Spring2D.prefab
```

Prefab结构：

```text
Spring2D
└─ Visual
```

根对象包含Static `Rigidbody2D`、非Trigger `BoxCollider2D`、返回`Spring`的`SurfaceSemantic2D`和负责接触分类、单次触发与重置的`Spring2D`。`Visual`包含`SpriteRenderer`和只负责图片切换的`SpringVisual2D`。

角色通过`ISpringBounceReceiver2D`接收法线与输出速度；弹簧不直接查找房间Player、不修改输入资产，也不在房间脚本中复制角色速度逻辑。

## 测试与验收

### EditMode/资产测试

- Prefab存在，根坐标和缩放正确，必需组件及内部引用完整。
- Rigidbody为Static，Collider非Trigger、尺寸`1 × 1`、中心`(0, 0.5)`。
- `Spring`语义固定、安全，Prefab不包含`MirrorSurface2D`。
- 两张Sprite引用正确，均为`128 PPU`、Point Filter、Full Rect和无压缩。
- Prefab不包含房间编号、正式世界坐标或房间专用脚本。

### PlayMode测试

- Player和正常重力MirrorClone从顶面落下达到相同法向输出速度，水平切向速度被保留。
- 左右侧面分别产生`-X`和`+X`的`8 units/s`输出，竖直速度被保留。
- 底面、向外运动和低于最小接近速度的接触不触发。
- 同一次连续接触不重复触发；完整离开后可以再次触发。
- 角点选择确定，顶面平局优先。
- 特殊墙面镜的旋转重力MirrorClone按世界接触面回弹。
- Jump松开不会截短沿局部反重力方向的弹簧弹射，普通跳跃规则保持不变。
- Player与MirrorClone同时接触时独立结算。
- 镜子放置查询拒绝弹簧，失败不生成镜子或镜像。
- MirrorClone死亡、镜子回收、Player死亡、手动重置和场景切换不留下接触、速度标记或压缩视觉。
- 改名或替换区域视觉不会改变碰撞、回弹和镜子放置结果。

### 人工试玩

- 普通跳跃`3 units`与弹簧`5 units`高度差可以直接感知。
- 侧面`8 units/s`足够明显，同时保留可修正的空中控制。
- 展开轮廓、实体碰撞和有效面一致；玩家不会意外站住、穿透或在墙角抖动。
- 第一次教学先安全展示顶面回弹，再展示侧面回弹，之后才与镜像、门、危险或其他区域机制组合。
