# 复活点系统

## 激活规则

- 复活点由Player接触后自动激活，不需要按 `E`。
- MirrorClone不能激活复活点。
- 同一时间只有一个当前复活点；新复活点激活后替换旧复活点。
- 激活时必须提供清晰的视觉和声音反馈。

## 生命周期

- 手动重置和玩家死亡重置保留当前复活点，并将Player移动到该位置。
- 离开房间后不保留该房间的当前复活点。
- 重新进入房间时使用房间入口作为初始复活位置，直到Player激活新的复活点。
- 复活点不是永久区域进度，不写入长期存档。

## 安全要求

- 复活位置必须能够容纳完整Player Collider，不能与墙壁、门、危险区域或动态物体重叠。
- 重置顺序遵循 `docs/systems/RESET_SYSTEM.md`：清理MirrorClone和交互占用、恢复房间瞬时状态，再放置Player。
