# 可推动箱子系统

## 已确认规则（2026-09-15）

用户批准制作可推动的黑色剪影箱子，并明确修正为“箱子掉落后可以触发压力开关”。

- 全局通用动态障碍，Prefab：`Assets/Prefabs/Gameplay/Props/PushableCrate2D.prefab`。视觉宽高1.2 units、根缩放1；用户手调碰撞体后已应用到共享Prefab：Size=(1.130806,1.1524358)，Offset=(0.012973785,-0.0064861774)，实体略收进剪影轮廓。
- Player与MirrorClone均通过实体接触推动箱子，不需要额外按钮，不抓取或拉动。双方沿已有各自移动轴运动，使用相同物理质量与碰撞规则；不修改输入映射、角色基础移动参数或施加身份专用推力。
- 箱子使用Dynamic Rigidbody2D、重力、连续碰撞与插值，锁定旋转；默认质量2、重力倍率3、摩擦0.10、弹性0。参数是共享Prefab物理调节值，不由房间覆盖角色移动参数。
- 箱子阻挡角色和实体地形，顶面可站立；按角色实际支撑面提供箱子的世界空间速度，复用既有表面承载，不直接移动角色、不建立父子关系。
- 箱子为安全、非静态`DynamicSurface`，不具有`MirrorSurface2D`，静止和移动时均不能放镜；箱子仍参与镜子与镜像生成空间占用检查。普通接触不伤害角色。
- 箱子可触发`Occupancy`、`DescendingLatch`以及`DescendingHold`压力开关。底部宽度与感应区有重叠即可，不要求完整宽度位于区内，底部位于感应厚度内，板面朝上且箱子获得向上的实体支撑；从上方下落后落稳可以触发。部分压住也有效；侧碰、从下方顶到及空中穿过均无效。多个Collider按同一Rigidbody去重，失效、禁用或移走后解除占用。
- 普通压力板在箱子移开后释放；下沉开关持续承压到底才永久锁存，中途移开取消进度。永久双板组沿用两板同时激活的规则。`FireballLatch`只接受火球，其他动态物体仍不自动获得压力开关资格。
- 门执行已请求的关闭动作时，箱子占据关闭范围则沿用防夹等待，不能直接穿过或推走箱子；箱子碰到已经关闭的门不会开门。
- 落入Fire_023危险水后箱子继续受重力沉底，不漂浮、不消失、不改变水的危险规则；玩家接触水仍死亡。
- 手动重置和Player死亡时，在开关占用及门结算前恢复箱子初始位置、朝向与零速度，清理物理接触。MirrorClone单独死亡或镜子回收不会重置箱子。
- 箱子位置与速度不写入存档、不跨Scene携带；重新进入房间由Prefab实例重新初始化。箱子已触发的永久开关仍按统一存档规则保留。

## 推箱表现（2026-09-15）

- `PlayerVisual2D`读取角色落地状态、输入方向及箱子侧面接触，显示专用前倾推箱动画；允许`0.035 units`接触间隙，不要求箱子已经产生速度，所以抵住受阻箱子也显示用力动作。
- 仅识别显式`PushableCrate2D`实体Collider；普通墙、Trigger、脚下支撑箱或忽略碰撞的对象不触发。
- Player与MirrorClone共用4帧Labnana剪影及`6 FPS`播放配置，MirrorClone使用其映射后的移动轴独立判断接触。
- 动画不施加推力、不改变移动速度、Collider、镜子输入或伤害时序；松键、反向、跳离或进入攀爬后切回对应状态。每次更新重新查询，不保存箱子引用，重置与场景切换不携带推箱状态。

## 最小回归要求

- 双方朝箱子侧面输入时显示推箱；箱子受阻仍显示。松键、反向、跳离、攀爬、死亡重置及场景切换后退出；站在箱顶、推动普通墙或接近Trigger不误触发；特殊墙镜使用映射后的移动轴检测。
- Player与MirrorClone推箱同规则；箱子受阻不穿墙，松手后下一物理步停止水平运动，不翻滚。
- 箱子上站立、跳离及表面速度只合成一次；箱面不能放镜，镜像生成不得穿箱。
- 箱子全部或部分落到开关上均激活；完全离开、侧碰和空中经过不激活；普通动态刚体无资格；FireballLatch拒绝箱子。
- 同板多个合格占用者不会互相覆盖，禁用/移走箱子立即重新结算；未锁存下沉进度释放后清除，永久结果不因箱子复位丢失。
- 重置恢复位置、旋转与零速度并解除旧开关占用；箱子先于开关及门复位。重新加载房间不保留位置。

## 松手立即停止（2026-09-15已确认）

- 用户明确要求松手立即停止，取代上方历史记录中的自然滑行减速。
- 箱子每个固定物理步查询左右侧面实际接触/0.035 units接触容差内的Player或MirrorClone。只有角色仍朝箱子输入时解除水平制动；MirrorClone使用映射后的世界移动方向，双方资格一致。站在箱顶、远处按键、反向离开、禁用/销毁角色或攀爬不算有效推动。
- 最后一个有效推动者停止推动后，在下一物理步将箱子水平速度清零并锁定X，避免角色剩余减速动量再次推走箱子；仍有其他合格角色推动则继续移动。再次贴近并朝箱子输入立即解除X锁定。
- 只锁水平位移，不锁Y、不修改重力或已有下落速度；箱子仍能落地、沉入水底并触发压力开关。旋转始终锁定。重置清除推动查询并恢复水平制动，不保存推动者引用或制动状态。

## 下沉开关承压修正（2026-09-16）

- 移动支撑面提供`ISurfaceMotionProvider2D`时，箱子使用其发布的表面速度判断是否落稳；其余支撑继续使用刚体接触点速度。避免MovePosition下沉过程中刚体速度暂时为零，导致承压反复丢失、开关回弹。实体支撑、空中过滤和水平即停规则不变；箱子完整脚印要求已由下方新规则取代。
