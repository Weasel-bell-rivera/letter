# SNOW_003：冰面初识

## 状态

- 当前状态：灰盒制作中
- 是否允许制作灰盒：是
- 批准范围：只使用静态普通地形、两段连续`FrozenGround`、两个入口、两个地图登记出口和Player跟随镜头；不引入敌人、门、压力板、落雪或`FreezingGround`

## 地图登记

- 地图编号：`SNOW_003`
- 地图来源：`docs/maps/MAP.md`
- 所属区域：雪之区域
- 相邻房间与连接方向：以 `docs/maps/MAP.md` 为准

## Unity资源

- 计划Scene：`Assets/Scenes/Levels/Snow/Snow_003.unity`
- 当前状态：使用标准Tilemap与通用Prefab创建灰盒
- 编辑器构建器：`Assets/Editor/Snow003RoomBuilder.cs`

## 房间定位

- 房间类型：雪区安全引入房
- 教学目标：让Player通过相反方向的两次滑行理解，进入`FrozenGround`前的方向和速度会持续保留，冰面上不能主动加速、反向或刹车
- 预期洞察：每次都应先在普通地面确定方向和速度，再进入冰面，并利用冰面末端的实体墙停止滑行
- 操作压力：低；没有敌人、冻结死亡地面、门、压力板、雪崩或精确计时
- 预计首次完成时间：`45～90秒`

## 地图连接

- `SNOW_002`位于本房上方，左侧返回出口连接`Snow_002/DEFAULT`
- `SNOW_004`位于本房下方，右侧前进出口连接`Snow_004/DEFAULT`
- 不增加其他房间连接

## 灰盒布局

```text
┌────────────────────────────────────────────┐
│                                            │
│      Exit  # I I I I I I I I I I = = =   │
│      ====  #                         ====   │
│                                      ===   │
│ Back  P  →      I I I I I I I    #         │
│============================================│
└────────────────────────────────────────────┘
```

- 普通起步区覆盖左侧，安全默认入口`DEFAULT`位于`(-9,-1.08)`并朝右
- 从`SNOW_004`返回使用上层终点入口`FROM_SNOW_004`，位于`(-9.75,2.92)`并朝右
- 连续寒冰覆盖网格`x=-4～6`、`y=-3`
- `x=7`处两格高普通地形墙作为确定性停止点
- Player从停止位置跳过矮墙，到达右侧普通地面
- 右侧普通台阶覆盖`x=9～11`、`y=-1`，用于登上上层起步台
- 上层普通起步台覆盖`x=5～8`、`y=1`；Player必须先向左加速再进入上层寒冰
- 上层寒冰覆盖`x=-5～4`、`y=1`，与下层形成方向相反的第二次速度承诺
- `x=-6`、`y=2～3`的两格高实体墙负责停止上层向左滑行
- 上层终点平台覆盖`x=-10～-7`、`y=1`；Player越过停止墙后进入`SNOW_004`出口
- 左侧保留返回`SNOW_002`的出口，且与入口保持距离，避免生成后立即触发

## Tilemap与Prefab

| 内容 | 实现 | 规则 |
|---|---|---|
| 普通地面、平台支撑和局部停止墙 | `Terrain` Tilemap | `StaticSolid`、安全、允许地面镜 |
| 连续冰面 | `FrozenGround` Tilemap | 安全静态寒冰、共享零摩擦材质、允许地面镜 |
| 左侧默认入口 | `RoomEntrance2D` | `DEFAULT`，由`SNOW_002`进入或直接加载时使用，初始朝右 |
| 上层终点返回入口 | `RoomEntrance2D` | `FROM_SNOW_004`，从`SNOW_004`返回时使用，初始朝右 |
| 返回出口 | `RoomExit2D.prefab` | 目标`Snow_002/DEFAULT` |
| 前进出口 | `RoomExit2D.prefab` | 上层终点平台`(-8,2)`；目标`Snow_004/FROM_SNOW_003` |

本房不创建房间专用运行时脚本，不序列化Player，不使用敌人Spawner。

## 相机

- 模式：常规Player跟随；MirrorClone和其他对象不作为跟随目标
- 正交尺寸：`7`
- 可显示边界：`X[-13,13]`、`Y[-7,7]`
- 跟随：水平与垂直均启用，平滑时间`0.15秒`；对应方向小于或等于完整视野时按边界居中
- 必须同时可见：下层入口与寒冰、右侧上升路线、上层起步台与反向寒冰、两处停止墙和前进出口

## 重置与风险

- Player死亡或手动重置回到本次进入时选中的入口（或已激活复活点），并清除速度、镜子和MirrorClone
- 静态Terrain和`FrozenGround`不参与运行时重置
- 提前跳起只能缩短当前冰面滑行，不得从下层直接跨越完整冰面或跳到上层终点
- 镜子不是通关要求；放置或回收镜子不能造成软锁
- 从`SNOW_004`返回使用上层终点左侧的`FROM_SNOW_004`入口`(-9.75,2.92)`，与出口Trigger保持安全间距；Player可从左侧安全落回下层
- 未运行PlayMode或人工试玩，两次撞墙后的跳跃容错、上升台阶间距和出口Trigger距离仍需后续试玩确认

## 最小验收标准

- Scene使用标准Tilemap分层，两段寒冰各自连续且无Tile缺口
- 普通地面和寒冰返回不同的显式表面语义
- 寒冰使用共享零摩擦PhysicsMaterial2D
- 两个出口保持共享Prefab连接且只指向地图登记邻居
- 下层不能直接跳到上层终点；上层反向冰面必须从右侧普通起步台进入
- Scene包含一个`DEFAULT`入口、一个`FROM_SNOW_004`入口、一个统一Player Spawner、一个重置系统和一个有边界的Player跟随相机
- Scene不包含房间专用玩法脚本、敌人、门、压力板、雪崩或冻结地面

## 实施限制

- 当前批准只覆盖上述安全冰面教学灰盒；不借本房新增或修改雪区全局规则。
