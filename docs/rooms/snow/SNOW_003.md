# SNOW_003：冰面初识

## 状态

- 当前状态：灰盒制作中
- 是否允许制作灰盒：是
- 批准范围：只实现静态普通地形、连续`FrozenGround`、入口、两个地图登记出口和固定单屏镜头

## 地图登记

- 地图编号：`SNOW_003`
- 地图来源：`docs/maps/MAP.md`
- 所属区域：雪之区域
- 相邻房间与连接方向：以 `docs/maps/MAP.md` 为准

## Unity资源

- 计划Scene：`Assets/Scenes/Levels/Snow/Snow_003.unity`
- 当前状态：使用标准Tilemap与通用Prefab创建灰盒
- 编辑器构建器：`Assets/Editor/Snow003RoomBuilder.cs`

## 房间定位

- 房间类型：雪区安全引入房
- 教学目标：让Player理解进入`FrozenGround`前的速度会持续保留，冰面上不能主动加速、反向或刹车
- 预期洞察：应在普通地面调整速度，并利用冰面末端的实体墙停止滑行
- 操作压力：低；没有敌人、冻结死亡地面、门、压力板、雪崩或精确计时
- 预计首次完成时间：`20～45秒`

## 地图连接

- `SNOW_002`位于本房上方，左侧返回出口连接`Snow_002/DEFAULT`
- `SNOW_004`位于本房下方，右侧前进出口连接`Snow_004/DEFAULT`
- 不增加其他房间连接

## 灰盒布局

```text
┌────────────────────────────────────────────┐
│                                            │
│                                  ####      │
│                                  #         │
│ Back  P  →      I I I I I I I    #   Exit │
│============================================│
└────────────────────────────────────────────┘
```

- 普通起步区覆盖左侧，入口位于`(-9,-1.08)`
- 连续寒冰覆盖网格`x=-4～6`、`y=-3`
- `x=7`处两格高普通地形墙作为确定性停止点
- Player可从停止位置跳过矮墙，到达右侧普通地面和`SNOW_004`出口
- 左侧保留返回`SNOW_002`的出口，且与入口保持距离，避免生成后立即触发

## Tilemap与Prefab

| 内容 | 实现 | 规则 |
|---|---|---|
| 普通地面、边界和停止墙 | `Terrain` Tilemap | `StaticSolid`、安全、允许地面镜 |
| 连续冰面 | `FrozenGround` Tilemap | 安全静态寒冰、共享零摩擦材质、允许地面镜 |
| 返回出口 | `RoomExit2D.prefab` | 目标`Snow_002/DEFAULT` |
| 前进出口 | `RoomExit2D.prefab` | 目标`Snow_004/DEFAULT` |

本房不创建房间专用运行时脚本，不序列化Player，不使用敌人Spawner。

## 相机

- 模式：固定单屏
- 正交尺寸：`7`
- 可显示边界：`X[-13,13]`、`Y[-7,7]`
- 必须同时可见：入口、普通起步区、完整寒冰、停止墙和前进出口

## 重置与风险

- Player死亡或手动重置回到默认入口，并清除速度、镜子和MirrorClone
- 静态Terrain和`FrozenGround`不参与运行时重置
- 提前跳起只能缩短在冰面上的滑行，不得直接跨越完整冰面
- 镜子不是通关要求；放置或回收镜子不能造成软锁
- 未运行PlayMode或人工试玩，停止墙后的跳跃容错和出口Trigger距离仍需后续试玩确认

## 最小验收标准

- Scene使用标准Tilemap分层，寒冰连续且无Tile缺口
- 普通地面和寒冰返回不同的显式表面语义
- 寒冰使用共享零摩擦PhysicsMaterial2D
- 两个出口保持共享Prefab连接且只指向地图登记邻居
- Scene包含一个默认入口、一个统一Player Spawner、一个重置系统和一个固定单屏相机
- Scene不包含房间专用玩法脚本、敌人、门、压力板、雪崩或冻结地面

## 实施限制

- 当前批准只覆盖上述安全冰面教学灰盒；不借本房新增或修改雪区全局规则。
