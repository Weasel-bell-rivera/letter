# FIRE_003：分流熔炉

## 状态

- 当前状态：灰盒中
- 主要目标：从顶部中央放镜后，让Player与MirrorClone沿左右蜿蜒通道协作下降并开启右下出口

## 已批准设计

- 左上角同时保留两个独立缺口：侧墙入口连接`FIRE_002`，相邻地板缺口通往左侧下降路线；两者不是二选一或同一个开口。
- Player从侧墙入口进入后，出生在下降口右侧的安全实体边缘。
- 地面镜把共享水平输入分成左右路线：MirrorClone进入左路，Player进入右路。
- 上下层之间设置四段互动：双向交叉占板开门、火球锁存门、投火者诱导与最终永久双压力板锁存。
- 中段不放岩浆；只使用安全静态地形、一个周期喷发器、门、压力板和固定Scene投火者。
- Player从右下角出口前往`FIRE_004`。

## 房间布局

- 相机边界：`X=-12～12`、`Y=-21～15`，横向固定、纵向跟随，正交尺寸`7`。
- 16:9下镜头可见宽约`24.89 units`，房间宽`24 units`，因此整层左右互动始终同时可见。
- 顶部平台表面`Y=12`；入口Collider中心`(-7.5,12.92)`，中央`X=0`为建议放镜点。
- 场景入口是左侧墙缺口`X=-12、Y=11～13`；左侧下降口是独立的两格地板缺口`X=-10～-9`；右侧下降口为`X=6～7`。
- Player入场后站在左侧下降口右沿，可沿完整平台向右到中央放镜。随后MirrorClone向左落入左侧地板缺口，Player向右落入右侧缺口。
- 互动层地面依次位于`Y=6`、`Y=-1`、`Y=-7`与`Y=-16`附近。
- 左右路线使用错位平台、外侧落口和中央门洞形成蜿蜒下降。

## 对象与控制关系

| ID | 类型 | 模式或目标 |
|---|---|---|
| Plate-Cross-A/B | 压力板 | `Occupancy`，分别控制对侧门 |
| Plate-Fireball-Latch | 压力板 | `FireballLatch`，控制中层锁存门 |

| Final-Door-Group | 永久锁存双压力板门控组 | `FIRE_003:DOOR_GROUP:01`；两板同时激活后永久开启出口门 |

所有动态对象均为通用Prefab实例，不新增房间专用运行时脚本。

## 预期解法

1. Player到顶部中央放镜，让MirrorClone向左、Player向右分流。
2. 两者沿外侧落口进入第一互动层，分别占用压力板，为对侧打开门洞。
3. 在第二层诱导`Thrower-E1`发射火球；角色离开射线后，火球命中`FireballLatch`并锁存打开中层门。
4. 在第三层让一侧占住交叉压力板，另一侧利用`Thrower-E2`蓄力后的窗口通过门廊。
5. 两者抵达最底层，同时踩下永久锁存双压力板；Player离板后从右下出口进入`FIRE_004`。

## 重置、失败与软锁

- Player死亡或手动重置：返回左上入口，清除镜子、MirrorClone、在途火球与普通压力板占用。
- 普通门和`FireballLatch`恢复关闭；投火者恢复Watching；周期喷发恢复初始相位。
- MirrorClone死亡只清除镜像并自动回收镜子；已永久锁存的最终门保持开启。
- 每个下降阶段保留安全落脚点；关键锁存前不得让Player落入无法重新放镜的位置。
- 门使用标准`1×2 units`实体和静态墙帽，不能从门上方绕过，也不能夹死角色。

## 验收标准

- 左上入口、顶部中央放镜点和右下出口关系清楚。
- Player与MirrorClone必须分别走左右路线；单角色无法完成最终双板锁存。
- 门与控制源可在行动前观察，火球锁存板不会响应角色接触。
- 中段没有岩浆Tile或岩浆Prefab。
- 出口门锁存后不会因MirrorClone消失或Player离板而关闭。
- 重置后普通机关、投火者和喷发器恢复初始状态。
