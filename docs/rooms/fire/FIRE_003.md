# FIRE-003：等待火息

## 状态

- 当前状态：已批准
- 是否允许制作灰盒：是
- 主要目标：只教学周期喷发

## 你填写

- 房间名称：等待火息
- 入口位置：左下角
- 出口位置：右下角
- 教学目标：观察并理解周期喷发的预警、危险和冷却阶段
- 必须出现的机关：单个周期喷发器、安全观察区域
- 禁止出现的机关：新的镜像组合、压力板、门以及其他未教学的新机制
- 希望玩家想到的关键解法：先观察完整循环，再在冷却阶段通过
- 难度：简单
- 预计完成时间：1～2分钟
- 其他要求：只设置一个喷发器，不依赖连续精确操作

## Codex补充

### 房间布局

- 建议灰盒尺寸：`20×8 units`。
- 左侧入口后设置安全观察区。
- 中央通道由一个向上喷发的喷发器覆盖。
- 喷发器两侧均有安全停留区，出口从入口可见。

```text
┌────────────────────────────┐
│              ↑             │
│ S────────── [F] ─────────E │
└────────────────────────────┘

F 周期喷发器    ↑ 危险方向
```

### 对象清单

| 对象 | 数量 | 作用 |
|---|---:|---|
| 入口 | 1 | 玩家出生点 |
| 出口 | 1 | 完成房间 |
| 周期喷发器 | 1 | 教学预警、危险和冷却阶段 |
| 安全观察区 | 2 | 喷发器两侧等待区域 |

### 初始状态

- 玩家位于左侧安全区。
- 喷发器从预警阶段开始。
- 原型周期建议为：预警`1.0s`、危险`1.0s`、冷却`2.0s`。
- 出口始终可用。

### 预期解法

1. 玩家停在安全区观察预警和喷发。
2. 玩家确认喷发进入冷却阶段。
3. 玩家通过中央区域并进入出口。

预期洞察：喷发周期固定且可预测，冷却阶段可以安全通过。

### 常见错误

- 玩家在预警后继续前进：危险阶段死亡并重置。
- 玩家一直等待：不会受罚，循环会持续重复。
- 玩家尝试跳过喷发：危险高度必须防止直接越过。

### 重置规则

- Player被喷发击中后执行死亡重置。
- Player返回入口，喷发器恢复到预警阶段起点。
- 手动重置产生相同结果。

### 软锁与逃课检查

- 两侧安全区必须完全处于危险Trigger之外。
- 喷发周期不得随机或根据玩家位置改变。
- 玩家错过时机后最多等待一个完整循环。
- 不设置第二个喷发器制造连续精确时机要求。

### 验收标准

- 三个阶段具有清晰且不同的反馈。
- 只有危险阶段会杀死Player或MirrorClone。
- 重置后始终回到预警阶段起点。
- 玩家可以用宽松时机稳定通过。
- 首次测试者能在一次观察或死亡后说出喷发规律。
