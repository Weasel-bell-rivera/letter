# FIRE-002：另一侧也会灼伤

## 状态

- 当前状态：已批准
- 是否允许制作灰盒：是
- 主要目标：教学镜像与岩浆的组合

## 你填写

- 房间名称：另一侧也会灼伤
- 入口位置：左下角
- 出口位置：右下角
- 教学目标：让玩家看见MirrorClone同样会被岩浆杀死，但镜像死亡不会杀死Player
- 必须出现的机关：镜子、镜像、岩浆、安全地面
- 禁止出现的机关：周期喷发、压力板、门以及其他未教学的新机制
- 希望玩家想到的关键解法：选择安全位置放镜子，并在移动Player时同时观察反向移动的MirrorClone
- 难度：简单
- 预计完成时间：1～2分钟
- 其他要求：镜像练习不作为硬性通关门槛，避免在引入连接机关前制造伪谜题

## Codex补充

### 房间布局

- 建议灰盒尺寸：`22×9 units`
- 主路线为左到右的连续安全地面，出口位于右侧。
- 房间中央设置清晰的安全放置区。
- 放置区左侧约`3 units`处设置一个短岩浆凹槽；地面镜生成的MirrorClone向左移动时会接近该凹槽。
- Player向右的路线保持安全，使玩家可以专注观察MirrorClone。

```text
┌────────────────────────────────┐
│                                │
│                                │
│ S────── ~~~ ──── M ─────────E  │
│                                │
└────────────────────────────────┘

S 入口    E 出口    M 建议放置区    ~ 岩浆
```

### 对象清单

| 对象 | 数量 | 作用 |
|---|---:|---|
| 入口 | 1 | 玩家出生点 |
| 出口 | 1 | 完成房间 |
| 建议放置区 | 1 | 用地面纹理提示安全放镜位置，不改变规则 |
| 岩浆Trigger | 1 | 展示MirrorClone死亡联动 |
| 静态地面 | 若干 | 主路线和岩浆两侧安全区域 |

### 初始状态

- 玩家从左侧进入并面向右。
- 镜子由玩家持有，MirrorClone不存在。
- 出口始终可用。
- 岩浆持续生效。

### 预期解法

1. 玩家走到中央建议放置区并面向右。
2. 玩家左键在脚底中心放置地面镜，MirrorClone与Player同位置生成；显示顺序为镜像在后、Player居中、镜子在前。
3. 玩家向右移动时观察MirrorClone从重叠位置向左分离。
4. 玩家通过跳跃输入让MirrorClone安全越过左侧岩浆，或观察一次镜像死亡后重新尝试。
5. 玩家沿安全主路线到达右侧出口。

预期洞察：Player和MirrorClone共享输入但独立碰撞；MirrorClone会被岩浆杀死，死亡后镜子自动回收而Player继续存活。

### 常见错误

- 玩家不放镜子直接到达出口：允许通关，但会错过练习；试玩时需观察视觉引导是否足够吸引玩家实验。
- MirrorClone走入岩浆：镜像消失、镜子回手，Player不死亡。
- 玩家在不安全位置放置导致生成空间被占用：放置失败，不改变当前状态。

### 重置规则

- Player进入岩浆时执行完整死亡重置。
- MirrorClone进入岩浆时只执行镜像死亡联动，不重置房间。
- 手动重置后Player回入口，镜子回手，MirrorClone消失。

### 软锁与逃课检查

- 主路线始终可达出口，不存在镜像死亡造成的软锁。
- 建议放置区只提供视觉提示，不应成为新的特殊表面规则。
- 岩浆凹槽必须让MirrorClone有充足时间观察和跳跃，不要求反应式极限操作。
- 若测试者普遍不使用镜子，应修改视觉引导，不能新增未批准的强制机关。

### 验收标准

- 地面镜在建议区域按正式规则生成于玩家脚底中心，MirrorClone与Player同位置生成后向反方向分离。
- Player右移时MirrorClone左移，双方跳跃方向向上。
- MirrorClone进入岩浆后消失、镜子回手、Player继续存活。
- Player进入岩浆后执行完整死亡重置。
- 不使用镜子也能通关，但首次测试者能注意到并理解镜像与岩浆的互动。
