# 火之区域房间索引

本文档是火之区域房间编号和批准状态的权威索引。房间文档存在不代表该房间已经批准进入正式开发。

## 状态定义

- 占位：只有编号或初步想法。
- 草案：已有设计，但尚未批准。
- 已批准：允许制作灰盒。
- 灰盒中：正在实现。
- 待试玩：灰盒完成，等待人工试玩验证。
- 正式：通过试玩并纳入区域流程。
- 废弃：停止使用。
