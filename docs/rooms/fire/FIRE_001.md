# FIRE_001：第一道热沟

## 状态

- 当前状态：待试玩
- 是否允许制作灰盒：是
- 主要目标：只教学岩浆伤害

## 你填写

- 房间名称：第一道热沟
- 入口位置：左下角
- 出口位置：右下角
- 教学目标：不使用文字，让玩家认识岩浆是没有实体支撑的致命区域
- 必须出现的机关：岩浆、安全地面
- 禁止出现的机关：周期喷发、压力板、门以及其他未教学的新机制
- 希望玩家想到的关键解法：观察危险边界，从安全助跑区跳过单个短岩浆沟
- 难度：简单
- 预计完成时间：1分钟
- 其他要求：死亡后快速重试；不要求极限跳跃

## Codex补充

### 房间布局

- 建议灰盒尺寸：`18×8 units`

- 玩家进入时即可同时看到岩浆、对岸和出口。

### 初始状态

- 玩家位于左侧入口并面向右。
- 岩浆持续生效，不移动、不喷发。
- 出口始终可用。
- 房间中没有必须使用的镜子谜题。

### 预期解法

1. 玩家观察岩浆与对岸。
2. 玩家从左侧安全地面起跳。
3. 玩家越过岩浆，在右侧安全地面落地。
4. 玩家进入出口。

预期洞察：岩浆没有实体支撑，接触会死亡，但可以用普通跳跃越过。

### 常见错误

- 玩家直接走入岩浆：立即死亡并快速重置，从结果理解危险规则。
- 玩家太早起跳落入岩浆：重试距离很短，不造成惩罚性重复。
- 玩家尝试在岩浆表面放镜子：放置失败并显示统一无效反馈。

### 重置规则

- 玩家接触岩浆后执行死亡重置。
- 玩家返回左侧入口；镜子回到手中；镜像消失。
- 岩浆保持初始持续危险状态。

### 软锁与逃课检查

- 房间不存在门、移动物体或可改变状态的机关，因此不应产生软锁。
- 岩浆沟不能窄到可以直接走过，也不能宽到接近极限跳跃。
- 地形上方不得存在可以完全绕开教学视线的隐藏路径。

### 验收标准

- Player进入岩浆后只触发一次死亡并正确重置。
- MirrorClone若被生成并进入岩浆，只执行镜像死亡联动，不杀死Player。
- 镜子不能放在岩浆表面。
- 使用普通非极限跳跃可以稳定通过。
- 首次游玩者无需文字即可辨认危险区域和出口。
