# CENTER_001：镜子的起点

## 状态

- 当前状态：已批准
- 是否允许制作灰盒：是
- 主要目标：建立游戏起点，教学基础移动，并让Player永久获得镜子能力

## 地图登记

- 地图编号：`CENTER_001`
- 地图来源：`docs/maps/MAP.md`
- 所属区域：教学区（Center）
- 房间类型：游戏起始房、核心能力获得房
- 出口数量：1
- 出口目标：`CENTER_002`

## Unity资源

- 计划Scene：`Assets/Scenes/Levels/Center/Center_001.unity`
- 当前状态：灰盒Scene已创建

## 房间定位

- 新游戏从本房间开始。
- Player在本房间出现时尚未获得镜子。
- 本房间负责让Player获得镜子，并第一次尝试放置和收回。
- 本房通过非文字视觉提示引导一次放置和收回，但不把完成练习作为开启出口的硬性条件；`CENTER_002`负责用必须依赖MirrorClone的谜题验证玩家理解。
- 预计完成时间：`1～2分钟`。
- 操作压力：低，不设置死亡危险和精确跳跃。

## 初始状态

- Player位于房间起点。
- 新存档中镜子作为永久拾取物出现在必经路线。
- 镜子尚未获得时，MirrorClone不存在，左键放置和右键收回均无效。
- 已经获得镜子的存档进入本房间时，不再生成镜子拾取物，Player保持镜子能力。

## 教学目标

1. 让玩家熟悉基础水平移动。
2. 让玩家完成一次宽松的普通跳跃。
3. 让玩家看见并主动接触镜子。
4. 让玩家理解镜子已经成为永久能力。
5. 在安全空间内完成一次放置镜子和收回镜子的操作。

## 房间流程

```text
Player出生
    → 水平移动区
    → 宽松跳跃区
    → 镜子展示与拾取区
    → 安全的镜子放置练习区
    → 出口
```

## 镜子获得规则

- 镜子放置在无法绕过的必经路线上，但不得使用门或危险物强迫拾取。
- 只有Player可以拾取镜子；MirrorClone在此时尚不存在。
- Player接触镜子后自动拾取，不增加新的交互按键。
- 镜子属于永久拾取物，拾取成功后立即请求写入持久化状态。
- 拾取成功后，场景中的镜子拾取物消失，左键放置和右键收回功能立即解锁。
- 存档写入失败时遵循`docs/systems/COLLECTIBLE_SYSTEM.md`：保留内存状态、记录错误并允许安全重试。
- 镜子一旦获得，不因死亡、手动重置、场景切换或重新启动游戏而丢失。

## 布局要求

- 入口、镜子和出口沿主要阅读方向依次出现。
- 镜子从接近拾取区之前就应清晰可见。
- 镜子拾取区前后均为静态、平坦、安全地面。
- 拾取后的练习区必须满足正式地面镜放置与MirrorClone生成空间要求。
- 出口位于练习区之后，玩家不能在未拾取镜子的情况下到达出口。
- 出口始终通往`CENTER_002`；拾取镜子后即可进入，不使用门强制检查是否完成放置和收回。
- 不使用岩浆、喷发、压力板、门、移动平台、特殊墙面镜或区域专属机制。

## 预期解法

1. Player从起点向前移动并通过宽松跳跃区。
2. Player沿必经路线接触镜子并永久获得能力。
3. Player在安全练习区按鼠标左键放置镜子，观察MirrorClone生成。
4. Player按鼠标右键收回镜子，MirrorClone消失。
5. Player进入出口。

## 重置规则

- 获得镜子前死亡或手动重置：Player返回起点，镜子拾取物保持未拾取状态并重新出现。
- 获得镜子后死亡或手动重置：Player返回起点；已放置镜子回手，MirrorClone消失；永久获得状态保留，拾取物不再出现。
- 离开并重新进入房间：按永久获得状态决定是否生成镜子拾取物。
- 已获得镜子的存档不得再次触发首次获得流程或重复写入奖励。

## 软锁与逃课检查

- 不得存在绕过镜子直接抵达出口的路线。
- 获得镜子前不得通过重置、场景切换或默认初始化凭空取得镜子。
- 获得镜子后即使立即重置，也必须保留能力。
- 放置失败、重复左键或收回镜子不能阻断出口路线。
- MirrorClone不能替代Player完成永久拾取。

## 验收标准

- 新存档从`CENTER_001`的指定起点生成Player。
- 拾取前左键和右键不会生成镜子或MirrorClone。
- Player接触镜子后立即解锁正式镜子操作。
- 拾取后能够在练习区成功放置和收回镜子。
- 获得状态在死亡、手动重置、场景切换和重新启动后保持。
- 已获得状态下重新进入房间时，拾取物不再出现。
- 未获得状态下无法绕过镜子进入出口。
- 房间无需文字说明即可让首次玩家完成基础流程。

## 当前实现状态

- 镜子拾取物在永久获得后不再出现；`Held`状态必须显示Player携带的镜子，放置时隐藏手持镜，回收时恢复手持镜。
