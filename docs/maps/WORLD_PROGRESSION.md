# 世界流程与区域解锁

本文档记录游戏起点、区域进入顺序和永久解锁条件。未在本文确认的区域顺序与解锁条件仍属待确定内容。

## 已确认：游戏起点

- 初始房间：`CENTER_001`
- 新游戏中的Player在`CENTER_001`出现。
- Player初始尚未获得镜子。
- Player在`CENTER_001`拾取镜子后，永久解锁镜子放置和收回能力。
- 镜子获得状态立即请求写入存档，并跨死亡、重置、场景切换和游戏重启保留。
- 具体房间流程见`docs/rooms/center/CENTER_001.md`。

- 是否允许玩家自由选择区域。

- 最终区域或结局的开放条件。
